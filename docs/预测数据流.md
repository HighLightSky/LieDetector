## 数据流详情

### 1. 特征提取阶段

| 提取器 | 输入 | 输出形状 | 说明 |
|--------|------|----------|------|
| FaceExtractor | 视频文件 | `(1, 16, 3, 160, 160)` | 16帧人脸图像，RGB，160×160 |
| AudioExtractor | 视频文件 | `(1, 768)` | Wav2Vec2 音频特征 |
| OpenFaceExtractor | 视频文件 | `(1, 16, 714)` | 16帧 OpenFace 特征 |

### 2. 模型推理阶段

#### 人脸分支
```
输入: (1, 16, 3, 160, 160)
  ↓ 展平
(16, 3, 160, 160)
  ↓ FacesModel (MobileNetV3 + FC)
(16, 2)
  ↓ 平均池化
(1, 2)
```

#### 音频分支
```
输入: (1, 768)
  ↓ AudioModel (FC layers)
(1, 2)
```

#### OpenFace 分支
```
输入: (1, 16, 714)
  ↓ 展平
(16, 714)
  ↓ OpenfaceModel (FC layers)
(16, 2)
  ↓ 平均池化
(1, 2)
```

#### 融合层
```
人脸 (1, 2) + 音频 (1, 2) + OpenFace (1, 2)
  ↓ 拼接
(1, 6)
  ↓ 融合网络 (FC layers)
(1, 2)
  ↓ Softmax
概率分布: [truth_prob, deception_prob]
```

## 模型架构

### MultiModalFusionModel

**总参数量**: 3,245,160

**子模型**:
1. **FacesModel**: MobileNetV3 骨干 + 可训练分类头
   - 骨干: 冻结的 MobileNetV3 (1024维特征)
   - 分类头: 1024 → 512 → 256 → 2
   
2. **AudioModel**: 全连接网络
   - 输入: 768维 Wav2Vec2 特征
   - 结构: 768 → 512 → 256 → 128 → 2
   
3. **OpenfaceModel**: 全连接网络
   - 输入: 714维 OpenFace 特征
   - 结构: 714 → 512 → 256 → 2

**融合层**:
- 输入: 6维 (3个子模型的输出拼接)
- 结构: 6 → 128 → 64 → 2

## 使用方法

### 基本用法

```python
python detect.py
```

### 自定义检测

```python
from detect import MultiModalFusionModel, detect_video
from dataloader import FaceExtractor, AudioExtractor, OpenFaceExtractor

# 初始化
device = 'cuda'
model = MultiModalFusionModel(device=device, use_openface=True)
face_extractor = FaceExtractor(num_frames=16)
audio_extractor = AudioExtractor(device=device)
openface_extractor = OpenFaceExtractor(num_frames=16)

# 检测
pred, probs = detect_video(
    video_path='path/to/video.mp4',
    model=model,
    face_extractor=face_extractor,
    audio_extractor=audio_extractor,
    openface_extractor=openface_extractor,
    device=device,
    verbose=True
)

print(f"预测: {'deception' if pred == 1 else 'truth'}")
print(f"置信度: {probs[pred]:.2%}")
```
