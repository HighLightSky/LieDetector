# 训练指南

本文档提供完整的训练流程说明。

## 快速开始

### 1. 准备环境

```bash
# 安装依赖
pip install -r requirements_win.txt
```

### 2. 准备数据

```bash
# 步骤1: 下载和切片视频
python -c "from dataloader.video_downloader import VideoDownloader; VideoDownloader().run()"

# 步骤2: 提取特征
python dataloader/precompute_features.py
```

### 3. 开始训练

```bash
# 使用默认参数训练
python train.py

# 或自定义参数
python train.py --num_epochs 50 --batch_size 16 --lr 1e-4
```

## 训练参数说明

### 数据参数

- `--csv_path`: 标签CSV文件路径（默认: `src/dataset/video_labels.csv`）
- `--features_dir`: 预计算特征目录（默认: `src/features`）
- `--use_openface`: 是否使用OpenFace特征（默认: True）
- `--val_split`: 验证集比例（默认: 0.2）

### 训练参数

- `--num_epochs`: 训练轮数（默认: 30）
- `--batch_size`: 批次大小（默认: 8）
- `--lr`: 学习率（默认: 1e-4）
- `--weight_decay`: 权重衰减（默认: 1e-4）
- `--patience`: 早停耐心值（默认: 5）

### 模型参数

- `--visual_hidden`: 视觉特征隐藏层维度（默认: 256）
- `--fusion_hidden`: 融合层隐藏层维度（默认: 128）
- `--dropout`: Dropout比例（默认: 0.3）
- `--uni_layers`: 单模态Transformer层数（默认: 2）
- `--uni_nhead`: 单模态Transformer注意力头数（默认: 4）
- `--com_heads`: 跨模态注意力头数（默认: 4）
- `--freeze_backbones`: 是否冻结预训练backbone（默认: True）

### 其他参数

- `--device`: 设备，cuda或cpu（默认: cuda）
- `--save_dir`: 模型保存目录（默认: checkpoints）
- `--resume`: 从检查点恢复训练
- `--num_workers`: DataLoader工作进程数（Windows建议设为0）
- `--seed`: 随机种子（默认: 42）

## 训练输出

训练完成后，会在保存目录生成以下文件：

```
checkpoints/
├── best_model.pth              # 最佳模型（验证准确率最高）
├── latest_model.pth            # 最新模型（最后一个epoch）
└── training_history.json       # 训练历史
```

## 使用训练好的模型

### 方法1: 使用LieDetector（推荐）

```python
from detector import LieDetector

# 从检查点加载
detector = LieDetector.from_checkpoint(
    checkpoint_path='checkpoints/best_model.pth',
    device='cuda'
)

# 预测
result = detector.predict('video.mp4', verbose=True)
print(f"预测: {result['label_cn']}")
print(f"置信度: {result['confidence']:.2%}")
```

### 方法2: 手动加载模型

```python
import torch
from models.fusion import FusionModel

# 创建模型
model = FusionModel(device='cuda')

# 加载权重
checkpoint = torch.load('checkpoints/best_model.pth')
model.load_state_dict(checkpoint['model_state_dict'])

# 推理
model.eval()
# ... 提取特征并推理
```

## 常见问题

### Q: 训练时出现CUDA out of memory

A: 减小batch_size或模型尺寸：
```bash
python train.py --batch_size 4 --visual_hidden 128 --fusion_hidden 64
```

### Q: 训练损失不下降

A: 尝试降低学习率：
```bash
python train.py --lr 5e-5
```

### Q: 验证准确率不提升

A: 增加正则化：
```bash
python train.py --dropout 0.5 --weight_decay 1e-3
```

### Q: 特征文件不存在

A: 先提取特征：
```bash
python dataloader/precompute_features.py
```
