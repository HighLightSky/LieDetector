# 过拟合问题分析与改进方案

## 一、训练数据分析

### 1.1 过拟合现象

从训练历史 `train_history_20260210_191826.json` 可以看到明显的过拟合：

**训练集表现（第30轮）：**
- 训练损失：0.607
- 训练准确率：93.40%

**验证集表现（第30轮）：**
- 验证损失：1.535
- 验证准确率：73.52%

**关键问题：**
1. **损失差距巨大**：验证损失(1.535)是训练损失(0.607)的2.5倍
2. **准确率差距显著**：训练准确率比验证准确率高约20%
3. **验证损失持续上升**：从第10轮(1.166)开始，验证损失单调上升至1.535
4. **最佳点出现过早**：验证准确率在第9轮达到峰值71.08%后开始下降

### 1.2 损失分解分析

观察各分支损失（第30轮）：

**训练集：**
- face: 0.691, openface: 0.667, audio: 0.657（单模态损失较高，正常）
- fa_au: 0.249, fa_of: 0.263（融合分支损失很低）
- fused: 0.212（最终融合损失极低，过拟合信号）

**验证集：**
- face: 0.689, openface: 0.679, audio: 0.657（单模态损失稳定）
- fa_au: 1.128, fa_of: 1.177（融合分支损失暴涨）
- fused: 0.771（最终融合损失高）

**核心问题：融合分支严重过拟合**
- fa_au训练损失0.249 vs 验证损失1.128（4.5倍差距）
- fa_of训练损失0.263 vs 验证损失1.177（4.5倍差距）

### 2.3 改进模型架构

#### 实验7：添加残差连接
**问题：** 深层网络训练不稳定

**建议修改（fusion.py）：**
```python
# 在E_uni编码器中添加残差连接
class UniEncoder(nn.Module):
    def forward(self, x):
        x = self.project_in(x)
        identity = x  # 保存输入
        x = self.encoder(x)
        x = self.output_norm(x)
        x = x + identity  # 残差连接
        return x
```

**预期效果：** 改善梯度流动，提升训练稳定性

#### 实验8：使用标签平滑

```python
criterion = nn.CrossEntropyLoss(label_smoothing=0.1)
```

**预期效果：** 减少过拟合，提升泛化能力

#### 实验9：特征级Dropout

#### 实验11：使用学习率预热
**建议修改（trainer.py）：**
```python
# 添加warmup scheduler
from torch.optim.lr_scheduler import LambdaLR

def get_warmup_scheduler(optimizer, warmup_epochs, total_epochs):
    def lr_lambda(epoch):
        if epoch < warmup_epochs:
            return (epoch + 1) / warmup_epochs
        return 0.5 * (1 + math.cos(math.pi * (epoch - warmup_epochs) / (total_epochs - warmup_epochs)))
    return LambdaLR(optimizer, lr_lambda)

# 使用：warmup_epochs=3, total_epochs=30
```

**预期效果：** 前期稳定训练，后期平滑收敛

#### 实验12：使用ReduceLROnPlateau

**建议调整：**

### 3.2 数据增强策略

**问题：** 数据集规模小（1151训练样本）

**建议实现（dataset.py）：**
```python
# 1. 时间裁剪：随机选择连续的子序列
def temporal_crop(features, crop_ratio=0.8):
    T = features.shape[1]
    crop_len = int(T * crop_ratio)
    start = random.randint(0, T - crop_len)
    return features[:, start:start+crop_len]

# 2. 时间扰动：随机丢弃部分帧
def temporal_dropout(features, drop_prob=0.1):
    mask = torch.rand(features.shape[1]) > drop_prob
    return features[:, mask]

# 3. 特征噪声：添加高斯噪声

    noise = torch.randn_like(features) * noise_std
    return features + noise
```

**预期效果：** 增加数据多样性，提升泛化能力

#### 实验14：Mixup数据增强
**建议实现：**
```python
# 在训练循环中使用Mixup
def mixup_data(x, y, alpha=0.2):
    lam = np.random.beta(alpha, alpha)
    batch_size = x.size(0)
    index = torch.randperm(batch_size)
    mixed_x = lam * x + (1 - lam) * x[index]
    y_a, y_b = y, y[index]
    return mixed_x, y_a, y_b, lam

# 损失计算
loss = lam * criterion(pred, y_a) + (1 - lam) * criterion(pred, y_b)
```

**预期效果：** 平滑决策边界，减少过拟合

## 七、总结

### 7.1 核心问题

1. **融合分支严重过拟合**：fa_au和fa_of的训练/验证损失差距达4.5倍
2. **模型复杂度过高**：相对于1151个训练样本，模型参数量可能过多
3. **正则化不足**：当前dropout(0.3)和weight_decay(0.0002)偏低
4. **验证损失单调上升**：从第10轮开始持续恶化，说明过拟合加剧

### 7.2 改进策略优先级

**立即执行（高优先级）：**
1. 提高dropout到0.5
2. 增加weight_decay到0.001
3. 降低学习率到5e-6
4. 简化模型（hidden维度减半，Transformer层数减少）
5. 调整损失权重（降低融合分支权重）

**后续尝试（中优先级）：**
1. 时序数据增强
2. 学习率预热
3. 梯度裁剪
4. 标签平滑

**可选探索（低优先级）：**

2. EMA
3. 更换优化器

通过上述改进，预期达到：

- **验证损失**：从1.535 → 1.0-1.2

1. **每次只改一个变量**：便于分析效果
