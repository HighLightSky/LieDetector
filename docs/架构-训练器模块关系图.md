## 模块职责矩阵

| 模块 | 职责 | 输入 | 输出 | 依赖 |
|------|------|------|------|------|
| LossComputer | 计算多任务损失 | 模型输出、标签 | 总损失、详细损失 | 无 |
| MetricsEvaluator | 评估指标 | 损失、预测、标签 | 准确率、平均损失 | 无 |
| TrainingLoop | 训练循环 | 数据加载器、优化器 | 训练指标 | LossComputer |
| ValidationLoop | 验证循环 | 数据加载器 | 验证指标 | LossComputer |
| CheckpointManager | 检查点管理 | 模型状态、epoch | 检查点文件 | 无 |
| HistoryTracker | 历史记录 | 训练/验证指标 | 历史数据 | 无 |
| FusionModelTrainer | 协调训练 | 模型、数据 | 训练完成 | 所有模块 |

### 3. 自定义指标评估

```python
class CustomMetricsEvaluator(MetricsEvaluator):
    def compute(self):
        # 添加新的评估指标
        metrics = super().compute()
        metrics['f1_score'] = self.compute_f1()
        return metrics
```

## 总结

模块化设计的关键特点：

1. **低耦合**：核心模块无依赖，可独立使用
2. **高内聚**：每个模块职责单一明确
3. **易扩展**：通过继承或组合添加新功能
4. **可测试**：每个模块可独立测试
5. **可复用**：模块可在其他项目中复用
