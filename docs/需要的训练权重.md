# 需要的训练权重总结

## 📊 权重需求概览

根据你的模型结构，需要的权重分为**两类**：

1. **预训练权重**（已自动下载）✅
2. **需要训练的权重**（需要你自己训练）🔥

---

## ✅ 已有的预训练权重

这些权重会在首次运行时**自动下载**，无需手动准备。

### 1. MobileNetV3 (FacesModel 骨干网络)

**位置**: `FacesModel.backbone`

**来源**: ImageNet 预训练

**下载方式**: 自动下载
```python
self.backbone = timm.create_model(
    'mobilenetv3_small_100',
    pretrained=True,  # 自动下载
    num_classes=0
)
```

**存储位置**: `~/.cache/torch/hub/checkpoints/mobilenetv3_small_100_*.pth`

**大小**: ~10 MB

**状态**: ❄️ 冻结（不训练）

**用途**: 提取面部图像的视觉特征

---

### 2. Wav2Vec2 (音频特征提取器)

**位置**: `AudioExtractor` 或 `Wav2Vec2Encoder`

**来源**: Facebook 预训练

**下载方式**: 自动下载
```python
from transformers import Wav2Vec2Processor, Wav2Vec2Model

processor = Wav2Vec2Processor.from_pretrained('facebook/wav2vec2-base')
model = Wav2Vec2Model.from_pretrained('facebook/wav2vec2-base')
```

**存储位置**: `~/.cache/huggingface/hub/models--facebook--wav2vec2-base/`

**大小**: ~360 MB

**状态**: ❄️ 冻结（不训练）

**用途**: 提取音频特征


## 📋 详细权重清单

### 第一层：子模型权重

#### 1. FacesModel.fc_block

**参数量**: ~0.8M

**结构**:
```python
nn.Sequential(
    nn.Linear(1024, 512),
    nn.ReLU(inplace=True),
    nn.BatchNorm1d(512),
    nn.Dropout(0.3),
    nn.Linear(512, 256),
    nn.ReLU(inplace=True),
    nn.BatchNorm1d(256),
    nn.Dropout(0.3),
    nn.Linear(256, 2),
)
```

**输入**: 1024 维（MobileNetV3 特征）

**输出**: 2 分类 logits

**训练方式**: 
- 可以单独预训练
- 或在 FusionModel 中端到端训练

**检查点参数**: `face_checkpoint`

---

#### 2. OpenfaceModel

**参数量**: ~0.5M

**结构**:
```python
nn.Sequential(
    nn.Linear(714, 512),
    nn.ReLU(inplace=True),
    nn.BatchNorm1d(512),
    nn.Dropout(0.3),
    nn.Linear(512, 256),
    nn.ReLU(inplace=True),
    nn.BatchNorm1d(256),
    nn.Dropout(0.3),
    nn.Linear(256, 2)
)
```

**输入**: 714 维（OpenFace 特征）

**输出**: 2 分类 logits

**训练方式**: 
- 可以单独预训练
- 或在 FusionModel 中端到端训练

**检查点参数**: `openface_checkpoint`

---

#### 3. AudioModel.fc

**参数量**: ~0.6M

**结构**:
```python
nn.Sequential(
    nn.Linear(768, 512),
    nn.BatchNorm1d(512),
    nn.ReLU(inplace=True),
    nn.Dropout(drop),
    nn.Linear(512, 256),
    nn.BatchNorm1d(256),
    nn.ReLU(inplace=True),
    nn.Dropout(drop),
    nn.Linear(256, 128),
    nn.BatchNorm1d(128),
    nn.ReLU(inplace=True),
    nn.Dropout(drop),
    nn.Linear(128, 2)
)
```

**输入**: 768 维（Wav2Vec2 特征）

**输出**: 2 分类 logits

**训练方式**: 
- 可以单独预训练
- 或在 FusionModel 中端到端训练

**检查点参数**: `audio_checkpoint`

---

### 第二层：融合层权重

#### 4. E_uni_face (单模态编码器)

**参数量**: ~0.3M

**结构**:
- Linear(1024 → 256)
- Transformer Encoder (2层, 4头)
- Pooling + Linear

**输入**: (B, T, 1024)

**输出**: (B, 256)

**训练方式**: 在 FusionModel 中训练

---

#### 5. E_uni_of (单模态编码器)

**参数量**: ~0.2M

**结构**:
- Linear(714 → 256)
- Transformer Encoder (2层, 4头)
- Pooling + Linear

**输入**: (B, T, 714)

**输出**: (B, 256)

**训练方式**: 在 FusionModel 中训练

---

#### 6. E_uni_audio (单模态编码器)

**参数量**: ~0.4M

**结构**:
- Linear(768 → 512)
- Linear(512 → 256)

**输入**: (B, 768)

**输出**: (B, 256)

**训练方式**: 在 FusionModel 中训练

---

#### 7. E_com_* (跨模态编码器)

**参数量**: ~0.5M

**包含**:
- E_com1_fa: Linear(1024 → 256)
- E_com2_fa: Linear(1024 → 256)
- E_com_au: Linear(768 → 256)
- E_com_of: Linear(714 → 256) + Pooling
- E_com_fa_au: CrossAttentionBlock
- E_com_fa_of: CrossAttentionBlock

**训练方式**: 在 FusionModel 中训练

---

#### 8. W (动态权重模块)

**参数量**: ~0.2M

**结构**:
```python
nn.Sequential(
    nn.Linear(768, 256),
    nn.ReLU(),
    nn.Dropout(0.2),
    nn.Linear(256, 3)
)
```

**输入**: (B, 768) - 三个模态拼接

**输出**: (B, 3) - 三个权重

**训练方式**: 在 FusionModel 中训练

---

#### 9. prob_fa_au (融合分类器)

**参数量**: ~0.15M

**结构**:
```python
nn.Sequential(
    nn.Linear(768, 256),
    nn.ReLU(inplace=True),
    nn.Dropout(dropout),
    nn.Linear(256, 2)
)
```

**输入**: (B, 768) - Face + Audio + 注意力

**输出**: (B, 2)

**训练方式**: 在 FusionModel 中训练

---

#### 10. prob_fa_of (融合分类器)

**参数量**: ~0.15M

**结构**:
```python
nn.Sequential(
    nn.Linear(768, 256),
    nn.ReLU(inplace=True),
    nn.Dropout(dropout),
    nn.Linear(256, 2)
)
```

**输入**: (B, 768) - Face + OpenFace + 注意力

**输出**: (B, 2)

**训练方式**: 在 FusionModel 中训练

## 🎯 训练策略

### 策略 1: 分阶段训练（推荐）

#### 阶段 1: 预训练子模型（可选）

```python
# 1. 训练 FacesModel
model = FacesModel(device='cuda')
# 训练 fc_block
# 保存: face_pretrained.pth

# 2. 训练 OpenfaceModel
model = OpenfaceModel()
# 训练整个模型
# 保存: openface_pretrained.pth

# 3. 训练 AudioModel
model = AudioModel()
# 训练 fc 层
# 保存: audio_pretrained.pth
```

#### 阶段 2: 训练融合模型

```python
# 加载预训练的子模型
model = FusionModel(
    device='cuda',
    face_checkpoint='face_pretrained.pth',
    openface_checkpoint='openface_pretrained.pth',
    audio_checkpoint='audio_pretrained.pth',
    freeze_backbones=True  # 冻结 MobileNetV3
)

# 冻结子模型，只训练融合层
for param in model.face.parameters():
    param.requires_grad = False
for param in model.openface.parameters():
    param.requires_grad = False
for param in model.audio.parameters():
    param.requires_grad = False

# 训练融合层
# 保存: fusion_model.pth
```

#### 阶段 3: 端到端微调（可选）

```python
# 解冻所有参数
for param in model.parameters():
    param.requires_grad = True

# 使用小学习率微调
optimizer = torch.optim.AdamW(model.parameters(), lr=1e-5)

# 微调
# 保存: fusion_model_finetuned.pth
```

---

### 策略 2: 端到端训练

```python
# 直接训练整个 FusionModel
model = FusionModel(
    device='cuda',
    freeze_backbones=True  # 保持 MobileNetV3 和 Wav2Vec2 冻结
)

# 训练所有可训练参数
optimizer = torch.optim.AdamW(
    filter(lambda p: p.requires_grad, model.parameters()),
    lr=1e-4
)

# 训练
# 保存: fusion_model_e2e.pth
```

## ⚠️ 注意事项

### 1. 预训练权重自动下载

- MobileNetV3 和 Wav2Vec2 会在首次运行时自动下载
- 确保网络连接正常
- 可以使用国内镜像加速

### 2. 子模型预训练（可选）

- 可以跳过子模型预训练，直接端到端训练
- 预训练可能提高收敛速度和最终性能
- 需要单模态数据集

### 3. 融合模型训练（必须）

- 融合层必须训练，没有预训练权重
- 需要多模态数据集
- 建议使用预提取特征加速训练

### 4. 检查点兼容性

- 确保检查点格式正确
- 使用 `strict=False` 处理部分加载
- 保存时包含必要的元信息
