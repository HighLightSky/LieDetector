# 训练历史保存优化

## 更新日期
2026-02-10

## 更新内容

### 1. 训练配置记录
训练历史文件现在会在头部包含完整的训练配置信息，包括：

- **基础配置**：开始时间、训练轮数、学习率、权重衰减、早停耐心值
- **优化器配置**：优化器类型、学习率调度器
- **损失权重**：各模态损失权重、熵正则化权重、权重一致性权重
- **数据配置**：批次大小、训练样本数、验证样本数
- **模型配置**：视觉隐藏层维度、融合层维度、Dropout、是否冻结backbone
- **设备信息**：训练设备（cuda/cpu）

### 2. 带时间戳的文件名
每次训练的历史文件都会使用唯一的时间戳文件名，格式为：
```
train_history_YYYYMMDD_HHMMSS.json
```

例如：`train_history_20260210_161117.json`

### 3. 独立的历史目录
所有训练历史文件现在保存在 `checkpoints/history/` 目录下，便于管理和查找。

## 修改的文件

### 1. `trainer/history_tracker.py`
- 添加 `config` 属性存储训练配置
- 添加 `set_config()` 方法设置训练配置
- 修改 `save()` 方法支持时间戳文件名和配置保存
- 导入 `datetime` 模块

### 2. `trainer/trainer.py`
- 在 `train()` 方法开始时收集训练配置
- 调用 `history_tracker.set_config()` 保存配置
- 修改 `save_history()` 方法使用带时间戳的文件名

### 3. `utils/experiment_tools.py`
- 修改 `_load_data()` 方法兼容新旧格式
- 添加 `config` 属性存储训练配置
- 添加 `print_config()` 方法打印配置信息
- 修改 `plot_combined_overview()` 方法动态获取可用模态

### 4. `run_utils.py`
- 添加 `get_latest_history_file()` 函数自动查找最新历史文件
- 更新主流程支持打印训练配置
- 添加错误处理

## 使用方法

### 训练时自动保存
训练时会自动保存带配置的历史文件：

```python
python train.py --num_epochs 30 --batch_size 8 --lr 1e-5
```

训练完成后，历史文件会保存到：
```
checkpoints/history/train_history_20260210_161117.json
```

### 查看训练配置和曲线
使用 `run_utils.py` 自动查找最新的历史文件并可视化：

```python
python run_utils.py
```

输出示例：
```
使用训练历史文件: checkpoints\history\train_history_20260210_161117.json

============================================================
训练配置信息
============================================================
start_time: 2026-02-10 16:00:00
num_epochs: 30
learning_rate: 1e-05
...
============================================================

训练曲线已保存到: experiment_history/svg\20260210_161336_combined_overview.svg
```

### 手动指定历史文件
也可以手动指定历史文件：

```python
from utils.experiment_tools import ExperimentVisualizer

visualizer = ExperimentVisualizer("checkpoints/history/train_history_20260210_161117.json")
visualizer.print_config()
visualizer.plot_combined_overview()
```

## 向后兼容性

代码完全兼容旧格式的历史文件（不包含 `training_config`）：

- `ExperimentVisualizer` 会自动检测文件格式
- 如果是旧格式，`config` 属性为空字典
- `print_config()` 会提示没有配置信息
- 所有可视化功能正常工作

## 优势

1. **完整记录**：每次训练的配置都被完整记录，便于复现实验
2. **易于管理**：时间戳文件名避免覆盖，所有历史都被保留
3. **自动查找**：工具会自动找到最新的历史文件
4. **向后兼容**：不影响旧代码和旧数据的使用
5. **便于对比**：可以轻松对比不同配置的训练效果

## 注意事项

1. 历史文件会随着训练次数增加而累积，建议定期清理旧文件
2. 如果需要保留特定实验的历史，可以手动重命名文件
3. `checkpoints/history/` 目录会自动创建，无需手动创建
