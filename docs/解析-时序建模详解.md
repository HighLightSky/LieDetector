## 概述

在谎言检测任务中，**时序信息至关重要**。人的面部表情、肢体语言、语音特征都是随时间变化的序列。融合模型通过**三个层次**的时序建模来捕捉这些动态特征。

---

## 时序建模的三个层次

### 层次1: 帧级特征提取（Frame-level）

**位置**: 在进入融合模型之前

**处理对象**: 
- 人脸图像序列: `(B, T, C, H, W)` - T个视频帧
- OpenFace特征序列: `(B, T, 714)` - T个时间步的面部特征

**方法**: 逐帧提取特征

```python
# 人脸特征提取
faces_proc = faces.view(B * T, C, H, W)  # 展平时间维度
face_back_feats = self.face.backbone(faces_proc)  # (B*T, 1024)
face_feats = face_back_feats.view(B, T, -1)  # 恢复时间维度 (B, T, 1024)
```

**输出**: 每一帧都有自己的特征向量

---

### 层次2: 序列编码（Sequence Encoding）

**位置**: `UniEncoder` - 单模态Transformer编码器

**核心组件**: `nn.TransformerEncoder`

#### 2.1 人脸序列编码

```python
self.E_uni_face = nn.Sequential(
    nn.Linear(1024, 256),           # 降维
    nn.ReLU(inplace=True),
    nn.Dropout(dropout),
    UniEncoder(                      # ⭐ Transformer编码器
        d_in=256, 
        d_model=256, 
        nhead=4,                     # 4个注意力头
        num_layers=2,                # 2层Transformer
        ff_hidden=512, 
        dropout=dropout
    ),
    Transpose(1, 2),                # (B, T, 256) → (B, 256, T)
    nn.AdaptiveAvgPool1d(1),        # 时间维度池化 → (B, 256, 1)
    nn.Flatten(),                   # → (B, 256)
    nn.Linear(256, 256),
    nn.ReLU(),
    nn.Dropout(0.1)
)
```

**工作原理**:

```
输入: (B, T, 1024) - T个时间步的人脸特征
  ↓
降维: (B, T, 256)
  ↓
Transformer编码器:
  - Self-Attention: 每个时间步关注其他所有时间步
  - 捕捉时序依赖关系
  - 输出: (B, T, 256) - 每个时间步的特征都包含了全局时序信息
  ↓
时间池化: (B, 256) - 聚合所有时间步的信息
```

#### 2.2 Transformer的时序建模能力

**Self-Attention机制**:

```python
# 在UniEncoder内部
class UniEncoder(nn.Module):
    def forward(self, x):
        # x: (B, T, 256)
        x = self.project_in(x)
        x = self.encoder(x)  # TransformerEncoder
        return x  # (B, T, 256)
```

**Attention计算**:

```
对于时间步 t，计算它与所有时间步的相关性：

Attention(Q, K, V) = softmax(QK^T / √d) V

其中：
- Q (Query): 当前时间步 t 的特征
- K (Key): 所有时间步的特征
- V (Value): 所有时间步的特征

结果：时间步 t 的输出 = 所有时间步的加权和
权重由相关性决定
```

**可视化示例**:

```
假设有4个时间步 [t1, t2, t3, t4]

t1 的输出 = 0.4*t1 + 0.3*t2 + 0.2*t3 + 0.1*t4
t2 的输出 = 0.2*t1 + 0.5*t2 + 0.2*t3 + 0.1*t4
t3 的输出 = 0.1*t1 + 0.2*t2 + 0.5*t3 + 0.2*t4
t4 的输出 = 0.1*t1 + 0.1*t2 + 0.3*t3 + 0.5*t4

每个时间步都"看到"了其他时间步的信息！
```

#### 2.3 OpenFace序列编码

```python
self.E_uni_of = nn.Sequential(
    nn.Linear(714, 256),
    nn.ReLU(inplace=True),
    nn.Dropout(dropout),
    UniEncoder(                      # ⭐ 同样使用Transformer
        d_in=256, 
        d_model=256, 
        nhead=4,
        num_layers=2,
        ff_hidden=512, 
        dropout=dropout
    ),
    Transpose(1, 2),
    nn.AdaptiveAvgPool1d(1),        # 时间池化
    nn.Flatten(),
    nn.Linear(256, 256),
    nn.ReLU(),
    nn.Dropout(0.1)
)
```

**处理流程相同**:
```
(B, T, 714) → Transformer → (B, T, 256) → 池化 → (B, 256)
```

### 层次3: 跨模态时序交互（Cross-Modal Temporal Interaction）

**位置**: `CrossAttentionBlock` - 跨模态注意力

**目的**: 让不同模态之间进行时序信息交换

#### 3.1 Face-Audio跨模态注意力

```python
# 准备特征
X_face1 = self.E_com1_fa(face_feats)  # (B, T, 256) - 人脸序列
X_au1 = self.E_com_au(audios)         # (B, 256) - 音频特征
X_au1 = X_au1.unsqueeze(1)            # (B, 1, 256) - 扩展时间维度

# 跨模态注意力
C_fa_au = self.E_com_fa_au(X_au1, X_face1, X_face1)  # (B, 256)
```

**工作原理**:

```
Query (Q): 音频特征 (B, 1, 256)
Key (K): 人脸序列 (B, T, 256)
Value (V): 人脸序列 (B, T, 256)

Cross-Attention:
音频特征去"查询"人脸序列的每个时间步
找出哪些时间步的人脸表情与音频最相关

输出: (B, 256) - 融合了时序信息的跨模态特征
```

**可视化**:

```
音频: "我没有做过这件事" (整体特征)
       ↓ Query
人脸序列: [微笑] [皱眉] [眼神飘移] [嘴角抽动]
          ↓     ↓      ↓         ↓
        0.1   0.2    0.5       0.2  ← Attention权重

输出 = 0.1*[微笑] + 0.2*[皱眉] + 0.5*[眼神飘移] + 0.2*[嘴角抽动]

模型发现：音频说"没做过"时，眼神飘移最相关（权重0.5）
这可能是说谎的信号！
```

#### 3.2 Face-OpenFace跨模态注意力

```python
X_face2 = self.E_com2_fa(face_feats)  # (B, T, 256)
X_of1 = self.E_com_of(of_feats)       # (B, 256)

C_fa_of = self.E_com_fa_of(X_of1, X_face2, X_face2)  # (B, 256)
```

**作用**: OpenFace特征（面部动作单元）与人脸图像序列交互

## 详细实现

### 完整的时序建模流程

```python
def forward(self, faces, openfaces, audios):
    # faces: (B, T, 3, 160, 160)
    # openfaces: (B, T, 714)
    # audios: (B, 768)
    
    # ========== 层次1: 帧级特征提取 ==========
    # 人脸
    faces_proc = faces.view(B * T, C, H, W)
    face_back_feats = self.face.backbone(faces_proc)  # (B*T, 1024)
    face_feats = face_back_feats.view(B, T, -1)       # (B, T, 1024)
    
    # OpenFace
    of_feats = openfaces  # (B, T, 714)
    
    # ========== 层次2: 序列编码（Transformer）==========
    # 人脸序列编码
    U_face = self.E_uni_face(face_feats)  # (B, T, 1024) → (B, 256)
    # 内部流程：
    # 1. Linear: (B, T, 1024) → (B, T, 256)
    # 2. Transformer: (B, T, 256) → (B, T, 256) [时序建模]
    # 3. Pooling: (B, T, 256) → (B, 256)
    
    # OpenFace序列编码
    U_of = self.E_uni_of(of_feats)  # (B, T, 714) → (B, 256)
    
    # 音频（无时序维度，直接编码）
    U_audio = self.E_uni_audio(audios)  # (B, 768) → (B, 256)
    
    # ========== 层次3: 跨模态时序交互 ==========
    # 准备跨模态特征
    X_face1 = self.E_com1_fa(face_feats)  # (B, T, 256)
    X_au1 = self.E_com_au(audios)         # (B, 256)
    X_au1 = X_au1.unsqueeze(1)            # (B, 1, 256)
    
    # Face-Audio跨模态注意力
    C_fa_au = self.E_com_fa_au(X_au1, X_face1, X_face1)
    # 音频查询人脸序列，找出最相关的时间步
    
    # Face-OpenFace跨模态注意力
    X_face2 = self.E_com2_fa(face_feats)  # (B, T, 256)
    X_of1 = self.E_com_of(of_feats)       # (B, 256)
    C_fa_of = self.E_com_fa_of(X_of1, X_face2, X_face2)
    
    # ========== 融合与分类 ==========
    # 动态权重学习
    W = self.W(U_face, U_of, U_audio)  # (B, 3)
    
    # 加权融合
    fuse_fa_au = torch.cat([U_face, U_audio, C_fa_au], dim=-1)
    fuse_fa_of = torch.cat([U_face, U_of, C_fa_of], dim=-1)
    
    # 分类
    logits_fa_au = self.prob_fa_au(fuse_fa_au)
    logits_fa_of = self.prob_fa_of(fuse_fa_of)
    
    # 最终融合
    fused_logits = W[:, 2:3]*logits_fa_au + W[:, 1:2]*logits_fa_of + W[:, 0:1]*logits_face
    
    return fused_logits
```

## 数据流分析

### 人脸特征的时序建模

```
原始视频帧
(B, T, 3, 160, 160)
    ↓
[帧级特征提取]
逐帧通过MobileNetV3
    ↓
帧级特征序列
(B, T, 1024)
    ↓
[降维]
Linear(1024 → 256)
    ↓
降维后的序列
(B, T, 256)
    ↓
[Transformer编码器] ⭐ 核心时序建模
Self-Attention:
- 每个时间步关注其他所有时间步
- 捕捉时序依赖关系
- 学习动态模式
    ↓
编码后的序列
(B, T, 256)
每个时间步都包含了全局时序信息
    ↓
[时间池化]
AdaptiveAvgPool1d
    ↓
聚合特征
(B, 256)
包含了整个序列的时序信息
```

### OpenFace特征的时序建模

```
OpenFace特征序列
(B, T, 714)
面部动作单元、头部姿态等
    ↓
[降维]
Linear(714 → 256)
    ↓
(B, T, 256)
    ↓
[Transformer编码器] ⭐ 时序建模
捕捉面部动作的时序模式
例如：
- 眉毛先上扬，然后皱眉
- 眼睛先睁大，然后眯起
- 嘴角先上扬，然后下垂
    ↓
(B, T, 256)
    ↓
[时间池化]
    ↓
(B, 256)
```

### 跨模态时序交互

```
人脸序列 (B, T, 256)    音频特征 (B, 256)
    ↓                        ↓
    Key/Value              Query
    ↓                        ↓
    └────── Cross-Attention ──┘
              ↓
        融合特征 (B, 256)
        
工作原理：
音频特征作为Query，去"查询"人脸序列
找出哪些时间步的人脸表情与音频最匹配

例如：
音频："我很高兴"
人脸序列：[皱眉] [微笑] [大笑] [平静]
Attention权重：[0.1] [0.3] [0.5] [0.1]
→ 模型发现"大笑"与"我很高兴"最匹配
```

## 为什么需要时序建模？

### 1. 捕捉动态变化

**说谎的时序特征**:
```
说真话：表情自然流畅
t1: 平静 → t2: 微笑 → t3: 微笑 → t4: 平静

说谎：表情不自然、有停顿
t1: 平静 → t2: 僵硬 → t3: 强颜欢笑 → t4: 眼神飘移
```

### 2. 识别微表情

**微表情持续时间很短（0.04-0.2秒）**:
```
正常表情序列：
[平静] [平静] [微笑] [微笑] [微笑] [平静]

包含微表情的序列：
[平静] [平静] [惊讶] [微笑] [微笑] [平静]
                 ↑
            微表情（仅1-2帧）
            
Transformer可以捕捉到这种短暂的变化！
```

### 3. 多模态时序对齐

**音频和视觉的时序关系**:
```
音频："我没有"
视觉：[说话] [停顿] [眼神飘移]

正常情况：音视频同步
说谎情况：可能有延迟或不一致

跨模态注意力可以发现这种不一致！
```

### 4. 长期依赖

**Transformer的优势**:
```
传统方法（如CNN）：只能看到局部窗口
Transformer：可以看到整个序列

例如：
t1: 开始说话（紧张）
t2-t10: 中间过程
t11: 结束（松了一口气）

Transformer可以关联t1和t11，发现"松了一口气"这个信号！
```

## 时序建模的关键优势

### 1. Self-Attention的全局视野

```python
# 传统CNN：只能看到局部
conv = nn.Conv1d(256, 256, kernel_size=3)
# 只能看到相邻的3个时间步

# Transformer：可以看到全局
transformer = nn.TransformerEncoder(...)
# 每个时间步都可以关注所有其他时间步
```

### 2. 位置编码（隐式）

```
Transformer内部会学习位置信息
知道哪个特征来自哪个时间步
保留了时序顺序
```

### 3. 多头注意力

```
4个注意力头 = 4种不同的时序模式

头1: 关注短期变化（相邻帧）
头2: 关注中期模式（几帧之间）
头3: 关注长期依赖（整个序列）
头4: 关注特定事件（如微表情）
```

---

## 总结

融合模型的时序建模是**多层次、多角度**的：

1. **帧级**: 提取每一帧的特征
2. **序列级**: Transformer编码整个序列，捕捉时序依赖
3. **跨模态级**: 不同模态之间的时序交互
4. **融合级**: 整合所有时序信息进行最终决策

这种设计使得模型能够：
- ✅ 捕捉微表情等短暂变化
- ✅ 识别表情的动态演变
- ✅ 发现音视频的时序不一致
- ✅ 学习长期依赖关系
- ✅ 多模态时序信息融合

**核心思想**: 谎言不仅体现在单个时刻的表情，更体现在表情随时间的变化模式中！
