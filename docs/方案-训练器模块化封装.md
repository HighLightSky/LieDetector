# 训练器模块化封装方案

## 概述

本文档说明如何将训练器进行模块化封装，将原本集中在单个类中的训练逻辑拆分为多个独立、可复用的模块。

## 模块化设计原则

1. **单一职责原则**：每个模块只负责一个特定功能
2. **高内聚低耦合**：模块内部功能紧密相关，模块间依赖最小化
3. **可测试性**：每个模块可以独立测试
4. **可扩展性**：易于添加新功能或替换现有模块

## 模块划分

### 1. LossComputer（损失计算模块）

**文件位置**：`trainer/loss_computer.py`

**职责**：
- 计算多任务损失
- 管理各任务的损失权重
- 支持动态调整权重

**核心接口**：
```python
class LossComputer:
    def __init__(self, loss_weights: Optional[Dict[str, float]] = None)
    def compute(self, output: Dict, labels: torch.Tensor, return_details: bool = False)
    def get_weights(self) -> Dict[str, float]
    def update_weights(self, new_weights: Dict[str, float])
```

**使用示例**：
```python
loss_computer = LossComputer(loss_weights={'face': 0.2, 'fused': 1.0})
total_loss, loss_details = loss_computer.compute(output, labels, return_details=True)
```

### 2. MetricsEvaluator（指标评估模块）

**文件位置**：`trainer/metrics_evaluator.py`

**职责**：
- 累计批次统计信息
- 计算准确率、平均损失等指标
- 支持详细损失跟踪

**核心接口**：
```python
class MetricsEvaluator:
    def reset()
    def update(self, loss: float, predictions: torch.Tensor, labels: torch.Tensor, 
               batch_size: int, loss_details: Dict = None)
    def compute(self) -> Dict[str, float]
    def get_accuracy(self) -> float
    def get_loss(self) -> float
```

**使用示例**：
```python
metrics = MetricsEvaluator()
metrics.reset()
for batch in dataloader:
    # ... 训练代码 ...
    metrics.update(loss.item(), predictions, labels, batch_size, loss_details)
final_metrics = metrics.compute()
```

### 3. TrainingLoop（训练循环模块）

**文件位置**：`trainer/training_loop.py`

**职责**：
- 执行单个epoch的训练循环
- 处理前向传播、反向传播
- 梯度检查和裁剪
- NaN/Inf检测和处理

**核心接口**：
```python
class TrainingLoop:
    def __init__(self, model: torch.nn.Module, loss_computer: LossComputer, device: str)
    def run_epoch(self, train_loader: DataLoader, optimizer: torch.optim.Optimizer, 
                  verbose: bool = True) -> Dict[str, float]
```

**使用示例**：
```python
training_loop = TrainingLoop(model, loss_computer, device='cuda')
train_metrics = training_loop.run_epoch(train_loader, optimizer, verbose=True)
```

### 4. ValidationLoop（验证循环模块）

**文件位置**：`trainer/validation_loop.py`

**职责**：
- 执行模型验证
- 计算验证集指标
- 无梯度模式下的前向传播

**核心接口**：
```python
class ValidationLoop:
    def __init__(self, model: torch.nn.Module, loss_computer: LossComputer, device: str)
    def run_validation(self, val_loader: DataLoader, verbose: bool = True) -> Dict[str, float]
```

**使用示例**：
```python
validation_loop = ValidationLoop(model, loss_computer, device='cuda')
val_metrics = validation_loop.run_validation(val_loader, verbose=True)
```

### 5. CheckpointManager（检查点管理模块）

**文件位置**：`trainer/checkpoint_manager.py`

**职责**：
- 保存和加载模型检查点
- 跟踪最佳模型
- 管理检查点文件

**核心接口**：
```python
class CheckpointManager:
    def __init__(self, save_dir: str = 'checkpoints')
    def save(self, filename: str, model_state: Dict, epoch: int, 
             history: Dict = None, extra_info: Dict = None)
    def load(self, filename: str, device: str = 'cuda') -> Dict[str, Any]
    def update_best(self, val_acc: float, epoch: int) -> bool
    def get_best_info(self) -> Dict[str, Any]
```

**使用示例**：
```python
checkpoint_manager = CheckpointManager(save_dir='checkpoints')
if checkpoint_manager.update_best(val_acc, epoch):
    checkpoint_manager.save('best_model.pth', model.state_dict(), epoch)
```

### 6. HistoryTracker（历史记录模块）

**文件位置**：`trainer/history_tracker.py`

**职责**：
- 记录训练历史
- 保存和加载历史数据
- 提供历史查询功能

**核心接口**：
```python
class HistoryTracker:
    def record_epoch(self, train_metrics: Dict, val_metrics: Dict)
    def get_history(self) -> Dict[str, List]
    def save(self, save_path: Path)
    def load(self, load_path: Path)
    def get_best_epoch(self) -> int
    def get_latest_metrics(self) -> Dict[str, float]
```

**使用示例**：
```python
history_tracker = HistoryTracker()
history_tracker.record_epoch(train_metrics, val_metrics)
history_tracker.save(Path('checkpoints/training_history.json'))
```

## 主训练器集成

**文件位置**：`trainer/trainer.py`

主训练器 `FusionModelTrainer` 现在作为各模块的协调者：

```python
class FusionModelTrainer:
    def __init__(self, model, train_loader, val_loader, device, save_dir, loss_weights):
        # 初始化各个模块
        self.loss_computer = LossComputer(loss_weights)
        self.training_loop = TrainingLoop(self.model, self.loss_computer, device)
        self.validation_loop = ValidationLoop(self.model, self.loss_computer, device)
        self.checkpoint_manager = CheckpointManager(save_dir)
        self.history_tracker = HistoryTracker()
    
    def train(self, num_epochs, lr, weight_decay, patience, verbose):
        # 使用各模块协调完成训练
        for epoch in range(num_epochs):
            train_metrics = self.training_loop.run_epoch(...)
            val_metrics = self.validation_loop.run_validation(...)
            self.history_tracker.record_epoch(train_metrics, val_metrics)
            if self.checkpoint_manager.update_best(...):
                self.checkpoint_manager.save(...)
```

## 模块化的优势

### 1. 代码可读性
- 每个模块职责清晰，代码更易理解
- 主训练器逻辑简洁，一目了然

### 2. 可维护性
- 修改某个功能只需修改对应模块
- 降低代码耦合，减少修改影响范围

### 3. 可测试性
- 每个模块可以独立单元测试
- 易于模拟（mock）依赖进行测试

### 4. 可复用性
- 模块可以在不同项目中复用
- 例如：`CheckpointManager` 可用于任何PyTorch项目

### 5. 可扩展性
- 易于添加新功能（如新的损失函数、评估指标）
- 可以替换模块实现而不影响其他部分

## 使用示例

### 基本使用（与原版相同）

```python
from trainer import FusionModelTrainer
from models.fusion import FusionModel

# 创建模型和数据加载器
model = FusionModel(...)
train_loader = DataLoader(...)
val_loader = DataLoader(...)

# 创建训练器
trainer = FusionModelTrainer(
    model=model,
    train_loader=train_loader,
    val_loader=val_loader,
    device='cuda',
    save_dir='checkpoints'
)

# 开始训练
trainer.train(num_epochs=30, lr=1e-5)
```

### 高级使用（自定义模块）

```python
from trainer import (
    FusionModelTrainer, LossComputer, TrainingLoop, 
    ValidationLoop, CheckpointManager, HistoryTracker
)

# 自定义损失权重
custom_loss_computer = LossComputer(loss_weights={
    'face': 0.3,
    'audio': 0.3,
    'fused': 1.5
})

# 创建训练器并替换损失计算模块
trainer = FusionModelTrainer(...)
trainer.loss_computer = custom_loss_computer

# 或者直接使用独立模块
training_loop = TrainingLoop(model, custom_loss_computer, 'cuda')
train_metrics = training_loop.run_epoch(train_loader, optimizer)
```

## 扩展指南

### 添加新的损失函数

修改 `LossComputer` 类：

```python
class LossComputer:
    def compute(self, output, labels, return_details=False):
        # 添加新的损失计算逻辑
        if 'new_modality' in output['logits']:
            new_loss = self.custom_loss_fn(output['logits']['new_modality'], labels)
            losses['new_modality'] = new_loss.item()
            total_loss += self.loss_weights.get('new_modality', 0.1) * new_loss
```

### 添加新的评估指标

扩展 `MetricsEvaluator` 类：

```python
class MetricsEvaluator:
    def __init__(self):
        super().__init__()
        self.precision_sum = 0.0
        self.recall_sum = 0.0
    
    def update(self, loss, predictions, labels, batch_size, loss_details=None):
        super().update(loss, predictions, labels, batch_size, loss_details)
        # 计算精确率和召回率
        precision = compute_precision(predictions, labels)
        recall = compute_recall(predictions, labels)
        self.precision_sum += precision * batch_size
        self.recall_sum += recall * batch_size
```

### 自定义训练循环

继承 `TrainingLoop` 类：

```python
class CustomTrainingLoop(TrainingLoop):
    def run_epoch(self, train_loader, optimizer, verbose=True):
        # 添加自定义逻辑
        metrics = super().run_epoch(train_loader, optimizer, verbose)
        # 额外处理
        return metrics
```

## 迁移指南

如果你有使用旧版训练器的代码，迁移非常简单：

### 旧版代码
```python
trainer = FusionModelTrainer(model, train_loader, val_loader)
trainer.train(num_epochs=30)
```

### 新版代码（完全兼容）
```python
trainer = FusionModelTrainer(model, train_loader, val_loader)
trainer.train(num_epochs=30)  # 接口完全相同
```

新版训练器保持了与旧版相同的公共接口，因此无需修改现有代码。

## 总结

训练器模块化封装将原本集中在单个类中的功能拆分为6个独立模块：

1. **LossComputer** - 损失计算
2. **MetricsEvaluator** - 指标评估
3. **TrainingLoop** - 训练循环
4. **ValidationLoop** - 验证循环
5. **CheckpointManager** - 检查点管理
6. **HistoryTracker** - 历史记录

这种设计提高了代码的可读性、可维护性、可测试性和可扩展性，同时保持了向后兼容性。
