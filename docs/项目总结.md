## 🎯 核心功能总览

### 三个子模型

| 模型 | 输入 | 输出 | 特征维度 | 预训练 |
|-----|------|------|---------|--------|
| **FacesModel** | 面部图像 (160×160) | 2分类 | 1024 | MobileNetV3 ✅ |
| **OpenfaceModel** | OpenFace特征 (714维) | 2分类 | 714 | 无 |
| **AudioModel** | Wav2Vec2特征 (768维) | 2分类 | 768 | Wav2Vec2 ✅ |

### 融合模型 (FusionModel)

**核心创新**:
1. **单模态编码器 (UniEncoder)**: Transformer处理时序信息
2. **跨模态注意力 (CrossAttention)**: 捕捉模态间互补信息
3. **动态权重模块 (W)**: 自适应学习模态重要性
4. **多层次融合**: 单模态 → 双模态 → 三模态融合

**输入格式**:
```python
faces:     (B, T, 3, 160, 160)  # B个样本，T帧RGB图像
openfaces: (B, T, 714)          # OpenFace特征序列
audios:    (B, 768)             # 音频特征向量
```

**输出格式**:
```python
{
    'probs': {
        'fused': (B, 2)  # 最终融合概率 [P(真话), P(谎言)]
    },
    'weights': (B, 3),   # 模态权重 [w_face, w_of, w_audio]
    'cos': {...}         # 模态间余弦相似度
}
```

## 📊 每个文件的作用

### 模型文件详解

#### 1. models/faces.py
**类**: `FacesModel`

**作用**: 从面部图像提取特征并分类

**关键组件**:
- `backbone`: MobileNetV3 (冻结，预训练)
- `fc_block`: 3层分类头 (1024→512→256→2)
- `prep`: 图像预处理流程

**方法**:
- `forward(x)`: 前向传播
- `predict_dir(dir)`: 批量预测目录中的图像
- `encode_dir(dir)`: 提取目录图像的平均特征

**特点**:
- 自动处理单样本BatchNorm问题
- 支持目录级批量处理
- 预训练权重自动下载

---

#### 2. models/openface.py
**类**: `OpenfaceModel`

**作用**: 处理OpenFace提取的面部动作单元特征

**架构**: 3层全连接网络
```
714 → 512 (ReLU + BN + Dropout)
    → 256 (ReLU + BN + Dropout)
    → 2   (Logits)
```

**方法**:
- `forward(x)`: 输入(B, 714)，输出(B, 2)

**特点**:
- 专门处理精细面部特征
- 捕捉微表情和AU变化
- 支持批量和序列输入

---

#### 3. models/audio.py
**类**: `Wav2Vec2Encoder`, `AudioModel`

**Wav2Vec2Encoder 作用**: 从音频文件提取特征
- 加载预训练Wav2Vec2模型
- 输入: 音频文件路径
- 输出: 768维特征向量

**AudioModel 作用**: 基于音频特征分类
- 4层全连接网络 (768→512→256→128→2)
- 可选MFCC特征融合

**函数**: `mfcc_vector()`
- 提取MFCC音频特征（可选）

**特点**:
- 预训练模型自动下载
- 支持任意长度音频
- 时序平均池化

---

#### 4. plan.py (核心文件)
**5个类，1个主模型**

##### `Transpose` 类
**作用**: 维度转置辅助模块
- 在Sequential中方便地转置维度
- 用于时序特征的维度调整

##### `W` 类 (动态权重模块)
**作用**: 自动学习三个模态的重要性权重
- 输入: 三个256维特征向量
- 输出: 3维权重向量 (softmax归一化)
- 网络: 768→256→3

**工作原理**:
```python
# 不同样本，权重不同
样本1: [0.4, 0.3, 0.3]  # Face最重要
样本2: [0.2, 0.2, 0.6]  # Audio最重要
```

##### `CrossAttentionBlock` 类
**作用**: 跨模态注意力机制
- 让一个模态"关注"另一个模态
- 捕捉模态间的互补信息
- 4头多头注意力

**应用**:
- Face ↔ Audio 注意力
- Face ↔ OpenFace 注意力

##### `UniEncoder` 类
**作用**: 单模态时序编码器
- 基于Transformer Encoder
- 建模帧间时序依赖
- 2层，4头注意力

**处理流程**:
```
输入序列 (B, T, D_in)
  → Linear投影
  → Transformer编码
  → 输出序列 (B, T, D_out)
```

##### `FusionModel` 类 ⭐ (核心模型)
**作用**: 多模态融合谎言检测主模型

**包含的子模块**:
1. 三个子模型 (face, openface, audio)
2. 单模态编码器 (E_uni_face, E_uni_of, E_uni_audio)
3. 跨模态编码器 (E_com_fa_au, E_com_fa_of)
4. 动态权重模块 (W)
5. 融合分类器 (prob_fa_au, prob_fa_of)

**前向传播流程**:
```
1. 预处理输入数据
2. 提取三个模态的特征
3. 单模态编码 (Transformer)
4. 计算动态权重
5. 跨模态注意力融合
6. 加权融合预测
7. 输出结果字典
```

**辅助方法**:
- `matrix_sqrt()`: 矩阵平方根
- `fit_gmm()`: GMM拟合
- `sinkhorn()`: 最优传输
- `compute_stats()`: 统计量计算
- `mmd()`: 最大均值差异

## 🔑 关键技术点

### 1. 多模态融合策略
```
Level 1: 单模态独立预测
  ├─ Face → P_face
  ├─ OpenFace → P_of
  └─ Audio → P_au

Level 2: 双模态融合
  ├─ Face + Audio → P_fa_au
  └─ Face + OpenFace → P_fa_of

Level 3: 动态加权融合
  └─ W * [P_face, P_fa_of, P_fa_au] → P_fused
```

### 2. 动态权重机制
- 不同样本，权重不同
- 自动发现最可靠的模态
- 提高融合鲁棒性

### 3. 跨模态注意力
- 捕捉模态间互补信息
- 例如: 面部微笑 + 语音颤抖 → 可能说谎
- 自动发现关联模式

### 4. 时序建模
- Transformer Encoder处理帧序列
- 捕捉时序依赖关系
- 支持任意长度序列

## 🔧 常见使用场景

### 场景1: 快速测试
```bash
# 1. 测试子模型
python test_models.py

# 2. 测试融合模型
python test_fusion_model.py
```

### 场景2: 单样本推理
```python
from plan import FusionModel
import torch

model = FusionModel(device='cuda')
model.eval()

# 准备数据
faces = torch.randn(1, 16, 3, 160, 160).cuda()
openfaces = torch.randn(1, 16, 714).cuda()
audios = torch.randn(1, 768).cuda()

# 推理
with torch.no_grad():
    output = model(faces, openfaces, audios)
    prob = output['probs']['fused'][0]
    pred = prob.argmax().item()

print(f"预测: {'谎言' if pred == 1 else '真话'}")
```

### 场景3: 批量训练
```python
model.train()
optimizer = torch.optim.AdamW(model.parameters(), lr=1e-4)
criterion = torch.nn.CrossEntropyLoss()

for epoch in range(num_epochs):
    for batch in dataloader:
        faces, openfaces, audios, labels = batch
        
        output = model(faces, openfaces, audios)
        loss = criterion(output['logits']['fused'], labels)
        
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
```
