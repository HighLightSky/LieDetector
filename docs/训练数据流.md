## 分阶段训练策略

### 阶段 1: 训练融合层
- **目标**: 学习如何融合三个子模型的输出
- **冻结**: 所有子模型
- **训练**: 只训练融合层（9,666参数）
- **学习率**: 1e-3
- **轮数**: 10 epochs

### 阶段 2: 微调分类头
- **目标**: 微调子模型的分类头以适应融合层
- **冻结**: 预训练骨干
- **训练**: 子模型分类头 + 融合层（1,727,304参数）
- **学习率**: 5e-4
- **轮数**: 10 epochs

### 阶段 3: 端到端微调
- **目标**: 整体优化所有可训练参数
- **冻结**: 只冻结预训练骨干
- **训练**: 所有分类头 + 融合层（1,727,304参数）
- **学习率**: 1e-4
- **轮数**: 10 epochs

## 数据流

### 训练数据流

```
视频文件 (*.mp4)
    ↓
特征提取 (预计算)
    ├─ 人脸: (T, 3, 160, 160)
    ├─ 音频: (768,)
    └─ OpenFace: (T, 714)
    ↓
数据集 (LieDetectionDataset)
    ↓
数据加载器 (DataLoader)
    ├─ faces: (B, T, 3, 160, 160)
    ├─ audios: (B, 768)
    └─ openfaces: (B, T, 714)
    ↓
模型 (MultiModalFusionModel)
    ├─ FacesModel: (B, T, 3, 160, 160) → (B, 2)
    ├─ AudioModel: (B, 768) → (B, 2)
    └─ OpenfaceModel: (B, T, 714) → (B, 2)
    ↓
融合层: (B, 6) → (B, 2)
    ↓
损失计算 & 反向传播
```

## 性能优化建议

### 1. 数据增强
在 `trainer/dataset.py` 中添加：
- 随机裁剪
- 颜色抖动
- 随机翻转
- 时间增强

### 2. 混合精度训练
使用 `torch.cuda.amp` 加速训练：
```python
from torch.cuda.amp import autocast, GradScaler

scaler = GradScaler()
with autocast():
    logits = model(faces, audios, openfaces)
    loss = criterion(logits, labels)
scaler.scale(loss).backward()
scaler.step(optimizer)
scaler.update()
```

### 3. 梯度累积
模拟更大的批大小：
```python
accumulation_steps = 4
for i, batch in enumerate(train_loader):
    loss = loss / accumulation_steps
    loss.backward()
    if (i + 1) % accumulation_steps == 0:
        optimizer.step()
        optimizer.zero_grad()
```

### 4. 学习率预热
```python
from torch.optim.lr_scheduler import LambdaLR

def warmup_lambda(epoch):
    if epoch < warmup_epochs:
        return (epoch + 1) / warmup_epochs
    return 1.0

scheduler = LambdaLR(optimizer, warmup_lambda)
```

## 故障排除

### 问题: 数据集为空

**解决**: 先提取特征
```bash
python -c "from dataloader.precompute_features import main; main()"
```

### 问题: CUDA out of memory

**解决**: 
- 减小 `batch_size`
- 减少 `num_frames`
- 使用梯度累积

### 问题: 训练不收敛

**解决**:
- 检查学习率（可能太大或太小）
- 检查数据标签是否正确
- 增加训练轮数
- 尝试不同的优化器

### 问题: 过拟合

**解决**:
- 增加 dropout
- 增加 weight_decay
- 使用数据增强
- 减少模型复杂度
