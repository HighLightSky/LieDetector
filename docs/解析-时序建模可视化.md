## 🔍 Transformer Self-Attention 详解

### 工作原理

```
输入序列: [t1, t2, t3, t4]

对于每个时间步，计算它与所有时间步的相关性：

时间步 t1:
  ┌────────────────────────────────┐
  │ 我与 t1 的相关性: 0.4 (自己)    │
  │ 我与 t2 的相关性: 0.3          │
  │ 我与 t3 的相关性: 0.2          │
  │ 我与 t4 的相关性: 0.1          │
  └────────────────────────────────┘
  输出 = 0.4*t1 + 0.3*t2 + 0.2*t3 + 0.1*t4

时间步 t2:
  ┌────────────────────────────────┐
  │ 我与 t1 的相关性: 0.2          │
  │ 我与 t2 的相关性: 0.5 (自己)    │
  │ 我与 t3 的相关性: 0.2          │
  │ 我与 t4 的相关性: 0.1          │
  └────────────────────────────────┘
  输出 = 0.2*t1 + 0.5*t2 + 0.2*t3 + 0.1*t4

... 以此类推
```

### 捕捉时序模式

```
说真话的表情序列:
┌────┬────┬────┬────┬────┐
│平静│微笑│微笑│微笑│平静│
└────┴────┴────┴────┴────┘
  ↓    ↓    ↓    ↓    ↓
流畅、自然的过渡
Transformer学到: 平滑的权重分布

说谎的表情序列:
┌────┬────┬────┬────┬────┐
│平静│僵硬│强笑│飘移│平静│
└────┴────┴────┴────┴────┘
  ↓    ↓    ↓    ↓    ↓
不自然、有跳跃
Transformer学到: 不连续的权重分布
```

## 🎯 跨模态注意力可视化

### Face-Audio Cross-Attention

```
音频: "我没有做过这件事"
       ↓ (Query)
       
人脸序列 (Key/Value):
┌──────┬──────┬──────┬──────┬──────┐
│ 微笑 │ 皱眉 │ 飘移 │ 抽动 │ 平静 │
└──────┴──────┴──────┴──────┴──────┘
   ↓      ↓      ↓      ↓      ↓
  0.1    0.2    0.5    0.2    0.0  ← Attention权重

输出 = 0.1*微笑 + 0.2*皱眉 + 0.5*飘移 + 0.2*抽动 + 0.0*平静

解释：
- 音频说"没做过"
- 但眼神飘移最相关（权重0.5）
- 这是说谎的信号！
```

### Face-OpenFace Cross-Attention

```
OpenFace特征: [眉毛上扬, 眼睛睁大, 嘴角下垂]
                    ↓ (Query)
                    
人脸图像序列 (Key/Value):
┌──────┬──────┬──────┬──────┐
│ 帧1  │ 帧2  │ 帧3  │ 帧4  │
└──────┴──────┴──────┴──────┘
   ↓      ↓      ↓      ↓
  0.3    0.4    0.2    0.1  ← Attention权重

输出 = 加权融合的跨模态特征

解释：
- OpenFace检测到面部动作单元
- 找出哪些帧的图像与这些动作最匹配
- 实现精确的多模态对齐
```

## 📊 时序信息的三个维度

### 1. 短期依赖（相邻帧）

```
t1 → t2 → t3
 ↓    ↓    ↓
捕捉快速变化，如微表情
```

### 2. 中期依赖（几帧之间）

```
t1 ─────→ t5 ─────→ t10
 ↓         ↓         ↓
捕捉表情演变，如从微笑到皱眉
```

### 3. 长期依赖（整个序列）

```
t1 ───────────────────→ t20
 ↓                       ↓
捕捉整体模式，如紧张→放松
```

## 🎨 实际案例分析

### 案例1: 检测微表情

```
正常表情序列（16帧）:
[平静][平静][平静][平静][平静][平静][平静][平静]
[平静][平静][平静][平静][平静][平静][平静][平静]

包含微表情的序列:
[平静][平静][平静][惊讶][平静][平静][平静][平静]
[平静][平静][平静][平静][平静][平静][平静][平静]
                 ↑
            微表情（仅1帧）

Transformer的Self-Attention:
- 第4帧（惊讶）会获得较高的注意力权重
- 因为它与其他帧不同
- 模型学会识别这种异常！
```

### 案例2: 音视频不一致

```
音频: "我很高兴" (t=0到t=2秒)
视觉: 
  t=0-1秒: [平静][平静]
  t=1-2秒: [皱眉][皱眉]  ← 与音频不一致！
  t=2-3秒: [微笑][微笑]

Cross-Attention会发现:
- 音频"高兴"与t=1-2秒的"皱眉"不匹配
- 这是说谎的信号！
```

### 案例3: 表情演变模式

```
说真话的演变:
[平静] → [思考] → [微笑] → [微笑] → [平静]
  ↓       ↓       ↓       ↓       ↓
流畅、自然的过渡

说谎的演变:
[平静] → [紧张] → [强笑] → [飘移] → [松气]
  ↓       ↓       ↓       ↓       ↓
不自然、有停顿

Transformer学习到:
- 真话: 平滑的attention权重分布
- 谎言: 跳跃的attention权重分布
```

## 💡 关键洞察

### 为什么Transformer适合时序建模？

1. **全局视野**: 每个时间步都能看到所有其他时间步
2. **并行计算**: 不像RNN需要顺序处理
3. **长期依赖**: 不会像RNN那样遗忘早期信息
4. **灵活的注意力**: 可以学习任意的时序模式

### 为什么需要跨模态时序交互？

1. **多模态对齐**: 音频和视觉需要时序对齐
2. **互补信息**: 不同模态在不同时刻提供不同信息
3. **一致性检查**: 检测音视频的时序不一致
4. **增强表示**: 融合多模态的时序信息

## 🎯 总结

融合模型的时序建模是**多层次、多角度**的：

```
┌─────────────────────────────────────┐
│  层次1: 帧级特征提取                 │
│  → 每一帧都有特征                    │
└─────────────────────────────────────┘
              ↓
┌─────────────────────────────────────┐
│  层次2: Transformer序列编码          │
│  → 捕捉时序依赖和动态模式             │
└─────────────────────────────────────┘
              ↓
┌─────────────────────────────────────┐
│  层次3: 跨模态时序交互                │
│  → 多模态时序信息融合                 │
└─────────────────────────────────────┘
              ↓
┌─────────────────────────────────────┐
│  最终: 动态权重融合                   │
│  → 整合所有时序信息进行决策            │
└─────────────────────────────────────┘
```

**核心思想**: 
- 谎言不仅体现在单个时刻
- 更体现在表情随时间的变化模式中
- 以及不同模态之间的时序关系中

**Transformer的优势**:
- ✅ 捕捉全局时序依赖
- ✅ 识别微表情等短暂变化
- ✅ 学习表情演变模式
- ✅ 发现音视频时序不一致
- ✅ 多模态时序信息融合
