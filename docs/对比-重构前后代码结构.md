# 重构前后代码结构对比

## 重构前（单体架构）

### 文件结构
```
trainer/
├── __init__.py
├── trainer.py (约430行)
├── dataset.py
└── README.md
```

### 类结构
```python
class FusionModelTrainer:
    def __init__(...)           # 初始化所有状态
    def compute_loss(...)       # 损失计算
    def train_epoch(...)        # 训练循环（约120行）
    def validate(...)           # 验证循环（约80行）
    def train(...)              # 主训练逻辑（约120行）
    def save_checkpoint(...)    # 保存检查点
    def load_checkpoint(...)    # 加载检查点
    def save_history(...)       # 保存历史
```

### 问题

1. **单个类过大**：430行代码集中在一个类中
2. **职责不清**：一个类负责多个功能
3. **难以测试**：无法独立测试各个功能
4. **难以复用**：功能耦合在一起，无法单独使用
5. **难以扩展**：修改一个功能可能影响其他功能

## 重构后（模块化架构）

### 文件结构
```
trainer/
├── __init__.py
├── trainer.py (约150行) ⬇️ 减少65%
├── loss_computer.py (约80行) ✨ 新增
├── metrics_evaluator.py (约90行) ✨ 新增
├── training_loop.py (约140行) ✨ 新增
├── validation_loop.py (约90行) ✨ 新增
├── checkpoint_manager.py (约100行) ✨ 新增
├── history_tracker.py (约90行) ✨ 新增
├── dataset.py
└── README.md
```

### 模块结构

#### 1. LossComputer（损失计算模块）
```python
class LossComputer:
    def __init__(loss_weights)
    def compute(output, labels, return_details)
    def get_weights()
    def update_weights(new_weights)
```

#### 2. MetricsEvaluator（指标评估模块）
```python
class MetricsEvaluator:
    def reset()
    def update(loss, predictions, labels, batch_size, loss_details)
    def compute()
    def get_accuracy()
    def get_loss()
```

#### 3. TrainingLoop（训练循环模块）
```python
class TrainingLoop:
    def __init__(model, loss_computer, device)
    def run_epoch(train_loader, optimizer, verbose)
    def _has_nan_output(output)
    def _has_nan_gradient()
```

#### 4. ValidationLoop（验证循环模块）
```python
class ValidationLoop:
    def __init__(model, loss_computer, device)
    def run_validation(val_loader, verbose)
```

#### 5. CheckpointManager（检查点管理模块）
```python
class CheckpointManager:
    def __init__(save_dir)
    def save(filename, model_state, epoch, history, extra_info)
    def load(filename, device)
    def update_best(val_acc, epoch)
    def get_best_info()
    def get_save_dir()
```

#### 6. HistoryTracker（历史记录模块）
```python
class HistoryTracker:
    def record_epoch(train_metrics, val_metrics)
    def get_history()
    def save(save_path)
    def load(load_path)
    def get_best_epoch()
    def get_latest_metrics()
```

#### 7. FusionModelTrainer（主训练器）
```python
class FusionModelTrainer:
    def __init__(...)           # 初始化各模块
    def train(...)              # 协调各模块完成训练
    def save_checkpoint(...)    # 兼容接口
    def load_checkpoint(...)    # 兼容接口
    def save_history(...)       # 兼容接口
```

### 优势

1. ✅ **单一职责**：每个模块只负责一个功能
2. ✅ **代码清晰**：主训练器从430行减少到150行
3. ✅ **易于测试**：每个模块可独立测试
4. ✅ **高度复用**：模块可在其他项目中使用
5. ✅ **易于扩展**：添加新功能只需扩展对应模块

## 使用对比

### 重构前
```python
# 只能整体使用
trainer = FusionModelTrainer(model, train_loader, val_loader)
trainer.train(num_epochs=30)

# 无法单独使用某个功能
# 无法自定义某个模块
```

### 重构后

#### 方式1：整体使用（完全兼容）
```python
trainer = FusionModelTrainer(model, train_loader, val_loader)
trainer.train(num_epochs=30)
```

#### 方式2：自定义模块
```python
# 自定义损失计算
custom_loss = LossComputer(loss_weights={'face': 0.3, 'fused': 1.5})
trainer = FusionModelTrainer(model, train_loader, val_loader)
trainer.loss_computer = custom_loss
trainer.train(num_epochs=30)
```

#### 方式3：独立使用模块
```python
# 只使用检查点管理
checkpoint_manager = CheckpointManager('my_checkpoints')
checkpoint_manager.save('model.pth', model.state_dict(), epoch=10)

# 只使用指标评估
metrics = MetricsEvaluator()
for batch in dataloader:
    metrics.update(loss, predictions, labels, batch_size)
```

## 扩展性对比

### 重构前：修改困难
```python
# 要添加新的损失函数，需要：
# 1. 修改 compute_loss 方法
# 2. 修改 train_epoch 方法
# 3. 修改 validate 方法
# 4. 可能影响其他功能
```

### 重构后：扩展简单
```python
# 要添加新的损失函数，只需：
# 1. 继承 LossComputer
class CustomLossComputer(LossComputer):
    def compute(self, output, labels, return_details=False):
        # 自定义逻辑
        pass

# 2. 使用自定义模块
trainer.loss_computer = CustomLossComputer()
```

## 测试对比

### 重构前：难以测试
```python
# 无法单独测试损失计算
# 无法单独测试指标评估
# 只能进行集成测试
```

### 重构后：易于测试
```python
# 可以单独测试每个模块
def test_loss_computer():
    loss_computer = LossComputer()
    output = {'logits': {...}}
    labels = torch.tensor([0, 1])
    loss, details = loss_computer.compute(output, labels, True)
    assert loss > 0
    assert 'face' in details

def test_metrics_evaluator():
    metrics = MetricsEvaluator()
    metrics.update(0.5, predictions, labels, 4)
    result = metrics.compute()
    assert 'accuracy' in result
```
