# 数据流与张量形状变化

本文档详细描述数据在模型中的流动过程，以及每一层的张量形状变化。

## 符号说明

- `B`: Batch size (批大小)
- `T`: Time steps (时间步数/帧数)
- `C`: Channels (通道数)
- `H`: Height (高度)
- `W`: Width (宽度)
- `D`: Dimension (特征维度)

## 完整数据流

### 阶段0: 原始输入

```python
# 输入视频
video_path = "path/to/video.mp4"

# 提取的原始数据
faces_raw: (T, C, H, W) = (16, 3, 160, 160)      # 16帧人脸图像
audios_raw: (D,) = (768,)                         # 音频特征
openfaces_raw: (T, D) = (16, 714)                 # OpenFace特征

# 添加batch维度
faces: (B, T, C, H, W) = (1, 16, 3, 160, 160)
audios: (B, D) = (1, 768)
openfaces: (B, T, D) = (1, 16, 714)
```

---

## 阶段1: 人脸分支 (Face Branch)

### 1.1 预处理
```python
# 输入
faces: (B, T, C, H, W) = (B, 16, 3, 160, 160)

# 归一化 (如果需要)
if faces.max() > 2.0:
    faces = faces / 255.0

# 展平时间维度
faces_proc: (B*T, C, H, W) = (B*16, 3, 160, 160)

# 插值到标准尺寸
faces_proc = F.interpolate(faces_proc, size=(160, 160))
# 输出: (B*16, 3, 160, 160)
```

### 1.2 MobileNetV3 Backbone (冻结)
```python
# 输入
faces_proc: (B*16, 3, 160, 160)

# 通过预训练backbone
with torch.no_grad():
    face_back_feats = self.face.backbone(faces_proc)
# 输出: (B*16, 1024)

# 重塑为序列
face_feats: (B, T, 1024) = (B, 16, 1024)
```

### 1.3 Face分类头 (用于辅助任务)
```python
# 输入
face_back_feats: (B*16, 1024)

# 通过分类头
face_frame_logits = self.face.fc_block(face_back_feats)
# 输出: (B*16, 2)

# 重塑并平均
face_frame_logits: (B, T, 2) = (B, 16, 2)
logits_face = face_frame_logits.mean(dim=1)
# 输出: (B, 2)

probs_face = F.softmax(logits_face, dim=1)
# 输出: (B, 2)
```

### 1.4 单模态编码器 E_uni_face
```python
# 输入
face_feats: (B, T, 1024) = (B, 16, 1024)

# Linear投影
x = Linear(1024, 256)(face_feats)
# 输出: (B, 16, 256)

# Transformer编码
x = UniEncoder(x)  # 2层Transformer, 4个注意力头
# 输出: (B, 16, 256)

# 转置
x = x.transpose(1, 2)
# 输出: (B, 256, 16)

# 自适应平均池化
x = AdaptiveAvgPool1d(1)(x)
# 输出: (B, 256, 1)

# 展平
x = x.flatten()
# 输出: (B, 256)

# 最终投影
U_face = Linear(256, 256)(x)
# 输出: (B, 256) ⭐
```

### 1.5 跨模态编码器 E_com (Face部分)
```python
# 输入
face_feats: (B, T, 1024) = (B, 16, 1024)

# 投影1 (用于Face-Audio)
X_face1 = Linear(1024, 256)(face_feats)
# 输出: (B, 16, 256)

# 投影2 (用于Face-OpenFace)
X_face2 = Linear(1024, 256)(face_feats)
# 输出: (B, 16, 256)
```

## 阶段2: OpenFace分支

### 2.1 预处理
```python
# 输入
openfaces: (B, T, 714) = (B, 16, 714)

# 展平
of_proc: (B*T, 714) = (B*16, 714)
```

### 2.2 OpenFace分类头 (用于辅助任务)
```python
# 输入
of_proc: (B*16, 714)

# 通过分类头
of_frame_logits = self.openface(of_proc)
# 输出: (B*16, 2)

# 重塑并平均
of_frame_logits: (B, T, 2) = (B, 16, 2)
logits_of = of_frame_logits.mean(dim=1)
# 输出: (B, 2)

probs_of = F.softmax(logits_of, dim=1)
# 输出: (B, 2)
```

### 2.3 单模态编码器 E_uni_of
```python
# 输入
of_feats: (B, T, 714) = (B, 16, 714)

# Linear投影
x = Linear(714, 256)(of_feats)
# 输出: (B, 16, 256)

# Transformer编码
x = UniEncoder(x)
# 输出: (B, 16, 256)

# 转置 + 池化 + 展平 + 投影 (同Face分支)
U_of: (B, 256) ⭐
```

### 2.4 跨模态编码器 E_com (OpenFace部分)
```python
# 输入
of_feats: (B, T, 714) = (B, 16, 714)

# 投影
X_of1 = Linear(714, 256)(of_feats)
# 输出: (B, 16, 256)

# 转置 + 池化 + 展平 + 投影
X_of1: (B, 256)
```

---

## 阶段3: 音频分支

### 3.1 音频分类头 (用于辅助任务)
```python
# 输入
audios: (B, 768)

# 通过分类头
logits_au = self.audio(audios)
# 输出: (B, 2)

probs_au = F.softmax(logits_au, dim=1)
# 输出: (B, 2)
```

### 3.2 单模态编码器 E_uni_audio
```python
# 输入
audios: (B, 768)

# MLP
x = Linear(768, 512)(audios)
# 输出: (B, 512)

x = ReLU()(x)
x = Dropout(0.3)(x)

x = Linear(512, 256)(x)
# 输出: (B, 256)

x = ReLU()(x)
U_audio = Dropout(0.3)(x)
# 输出: (B, 256) ⭐
```

### 3.3 跨模态编码器 E_com (Audio部分)
```python
# 输入
audios: (B, 768)

# 投影
X_au1 = Linear(768, 256)(audios)
# 输出: (B, 256)
```

---

## 阶段4: 跨模态注意力

### 4.1 Face-Audio交互
```python
# 输入
X_au1: (B, 256)        # Query
X_face1: (B, 16, 256)  # Key, Value

# 扩展Query维度
q = X_au1.unsqueeze(1)
# 输出: (B, 1, 256)

# Multi-Head Attention (4个头)
C_fa_au, _ = MultiheadAttention(q, X_face1, X_face1)
# 输出: (B, 1, 256)

# 压缩
C_fa_au = C_fa_au.squeeze(1)
# 输出: (B, 256) ⭐
```

### 4.2 Face-OpenFace交互
```python
# 输入
X_of1: (B, 256)        # Query
X_face2: (B, 16, 256)  # Key, Value

# 同样的注意力机制
C_fa_of: (B, 256) ⭐
```

---

## 阶段5: 动态权重学习

```python
# 输入
U_face: (B, 256)
U_of: (B, 256)
U_audio: (B, 256)

# 拼接
concatenated = torch.cat([U_face, U_of, U_audio], dim=1)
# 输出: (B, 768)

# MLP
x = Linear(768, 256)(concatenated)
# 输出: (B, 256)

x = ReLU()(x)
x = Dropout(0.2)(x)

W_scores = Linear(256, 3)(x)
# 输出: (B, 3)

# Softmax归一化
W = F.softmax(W_scores, dim=1)
# 输出: (B, 3) ⭐
# W[:, 0] = w_face
# W[:, 1] = w_of
# W[:, 2] = w_audio
```

---

## 阶段6: 加权与融合

### 6.1 加权单模态表示
```python
# 输入
U_face: (B, 256)
U_of: (B, 256)
U_audio: (B, 256)
W: (B, 3)

# 加权
U_face_weighted = W[:, 0:1] * U_face
# 输出: (B, 256)

U_of_weighted = W[:, 1:2] * U_of
# 输出: (B, 256)

U_audio_weighted = W[:, 2:3] * U_audio
# 输出: (B, 256)
```

### 6.2 Face-Audio融合
```python
# 输入
U_face_weighted: (B, 256)
U_audio_weighted: (B, 256)
C_fa_au: (B, 256)

# 拼接
fuse_fa_au = torch.cat([U_face_weighted, U_audio_weighted, C_fa_au], dim=-1)
# 输出: (B, 768)

# 分类头
x = Linear(768, 256)(fuse_fa_au)
# 输出: (B, 256)

x = ReLU()(x)
x = Dropout(0.3)(x)

logits_fa_au = Linear(256, 2)(x)
# 输出: (B, 2)

probs_fa_au = F.softmax(logits_fa_au, dim=1)
# 输出: (B, 2)
```

### 6.3 Face-OpenFace融合
```python
# 同样的流程
fuse_fa_of: (B, 768)
logits_fa_of: (B, 2)
probs_fa_of: (B, 2)
```

---

## 阶段7: 最终融合

```python
# 输入
probs_face: (B, 2)
probs_fa_au: (B, 2)
probs_fa_of: (B, 2)
W: (B, 3)

# 加权组合
fused_probs = (
    W[:, 2:3] * probs_fa_au +  # w_audio × P(Face-Audio)
    W[:, 1:2] * probs_fa_of +  # w_of × P(Face-OpenFace)
    W[:, 0:1] * probs_face     # w_face × P(Face)
)
# 输出: (B, 2) ⭐

# 最终预测
prediction = torch.argmax(fused_probs, dim=1)
# 输出: (B,)
# 0 = Truth, 1 = Deception
```

## 完整形状变化总结

### 输入
```
faces:      (B, 16, 3, 160, 160)
openfaces:  (B, 16, 714)
audios:     (B, 768)
```

### 中间表示
```
face_feats:     (B, 16, 1024)  → U_face:  (B, 256)
of_feats:       (B, 16, 714)   → U_of:    (B, 256)
audios:         (B, 768)       → U_audio: (B, 256)

X_face1/2:      (B, 16, 256)
X_of1:          (B, 256)
X_au1:          (B, 256)

C_fa_au:        (B, 256)
C_fa_of:        (B, 256)

W:              (B, 3)
```

### 输出
```
logits_face:    (B, 2)
logits_of:      (B, 2)
logits_au:      (B, 2)
logits_fa_au:   (B, 2)
logits_fa_of:   (B, 2)

probs_fused:    (B, 2) ⭐ 最终输出
weights:        (B, 3)
```

## 批处理示例

假设 `B=4, T=16`:

```python
# 输入
faces:      (4, 16, 3, 160, 160)  # 4个视频，每个16帧
openfaces:  (4, 16, 714)          # 4个视频的OpenFace特征
audios:     (4, 768)              # 4个视频的音频特征

# 中间
U_face:     (4, 256)              # 4个人脸表示
U_of:       (4, 256)              # 4个OpenFace表示
U_audio:    (4, 256)              # 4个音频表示
W:          (4, 3)                # 4个样本的权重

# 输出
probs_fused: (4, 2)               # 4个预测概率
# [[0.7, 0.3],  # 样本1: 70% Truth
#  [0.4, 0.6],  # 样本2: 60% Deception
#  [0.8, 0.2],  # 样本3: 80% Truth
#  [0.3, 0.7]]  # 样本4: 70% Deception
```

---

## 关键观察

1. **维度压缩**: 
   - 1024/714/768维 → 256维 (统一表示空间)

2. **时序处理**: 
   - (B, T, D) → Transformer → (B, D) (时序信息编码)

3. **注意力机制**: 
   - Query: (B, 1, 256) × Key/Value: (B, T, 256) → (B, 256)

4. **多任务输出**: 
   - 6个不同的2维logits/probs

5. **动态权重**: 
   - 每个样本有自己的权重 W: (B, 3)

6. **信息保留**: 
   - 始终使用高维特征(256维)，不压缩到2维
