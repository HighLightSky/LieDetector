# 损失计算说明

## 总损失组成

```
total_loss = fused_loss + auxiliary_losses + entropy_reg + weight_mse
```

### 1. 融合损失 (fused_loss)

**主要分类损失**，权重最高（默认 1.0）

```python
fused_logits = output['logits']['fused']  # (B, 2)
fused_loss = CrossEntropyLoss(fused_logits, labels)
total_loss += fused_loss * 1.0
```

### 2. 辅助损失 (auxiliary_losses)

各模态的分类损失，帮助训练各个子模块

```python
for key in ['face', 'openface', 'audio', 'fa_au', 'fa_of']:
    logits = output['logits'][key]  # (B, 2)
    loss = CrossEntropyLoss(logits, labels)
    total_loss += loss * weight[key]
```

**默认权重**:
- `face`: 0.2
- `openface`: 0.2
- `audio`: 0.2
- `fa_au`: 0.15
- `fa_of`: 0.15

### 3. 熵正则化 (entropy_reg)

鼓励动态权重 W 明确化（不要太均匀）

```python
W = output['weights']  # (B, 3) - [w_face, w_openface, w_audio]
entropy_reg = (W * log(W)).sum(dim=1).mean()
total_loss += entropy_reg * 0.2
```

**解释**:
- 当 W = [1/3, 1/3, 1/3] 时，entropy_reg ≈ -1.099（最大熵）
- 当 W = [1, 0, 0] 时，entropy_reg = 0（最小熵）
- 负的熵正则化鼓励权重分化

### 4. 权重一致性损失 (weight_mse)

让动态权重 W 与各模态的实际性能对齐

```python
# 计算各模态在正确类别上的概率
p_face = face_probs[labels]
p_openface = openface_probs[labels]
p_audio = audio_probs[labels]

# 归一化为权重
p_norm = normalize([p_face, p_openface, p_audio])

# MSE损失
weight_mse = MSE(W, p_norm)
total_loss += weight_mse * 0.05
```

**解释**: 如果某个模态表现好（高概率），其权重应该更大

## 损失权重配置

在 `train.py` 中配置：

```python
loss_weights = {
    'face': 0.2,
    'openface': 0.2,
    'audio': 0.2,
    'fa_au': 0.15,
    'fa_of': 0.15,
    'fused': 1.0
}

trainer = FusionModelTrainer(
    model=model,
    train_loader=train_loader,
    val_loader=val_loader,
    loss_weights=loss_weights
)

trainer.loss_computer.ent_reg_weight = 0.2
trainer.loss_computer.w_mse_weight = 0.05
```

## 损失值解释

### 正常范围

- **fused**: 0.0 ~ 0.693
  - 0.693: 完全不确定（[0.5, 0.5]）
  - 0.0: 完全确定（[1.0, 0.0] 或 [0.0, 1.0]）

- **辅助损失**: 类似 fused

- **entropy_reg**: -1.099 ~ 0
  - -1.099: 完全均匀（[1/3, 1/3, 1/3]）
  - 0: 完全集中（[1, 0, 0]）

- **weight_mse**: 0.0 ~ 0.5
  - 0.0: 权重完全对齐
  - 0.5: 权重完全不对齐

### 训练进度

**初始状态**（随机初始化）:
```
fused: 0.693
entropy_reg: -1.099
weight_mse: 0.1~0.3
```

**训练中期**:
```
fused: 0.3~0.5
entropy_reg: -0.8~-0.5
weight_mse: 0.05~0.1
```

**训练后期**（收敛）:
```
fused: 0.1~0.3
entropy_reg: -0.3~-0.1
weight_mse: 0.01~0.05
```

## 数值稳定性

### 使用 clamp 而不是 nan_to_num

```python
# ✓ 正确
eps = 1e-7
probs = torch.clamp(probs, min=eps, max=1.0-eps)

# ✗ 错误（破坏梯度）
probs = torch.nan_to_num(probs, nan=0.0)
```

### NaN 检测

```python
if torch.isnan(loss) or torch.isinf(loss):
    print("[WARNING] 跳过批次")
    continue
```

## 调试技巧

### 查看详细损失

训练时会自动打印：
```
详细损失:
  fused: 0.6890
  face: 0.6890
  openface: 0.6725
  audio: 0.6613
  fa_au: 0.6611
  fa_of: 0.6866
  entropy_reg: -1.0887
  weight_mse: 0.0040
```

### 判断训练状态

1. **fused 不下降**: 模型没有学习
   - 检查学习率
   - 检查是否有 NaN

2. **entropy_reg 不变**: 权重没有学习
   - 检查 W 模块
   - 增加 ent_reg_weight

3. **weight_mse 很高**: 权重与性能不对齐
   - 正常现象（训练初期）
   - 会随训练逐渐下降

## 当前损失计算方式

### 统一使用 CrossEntropyLoss

```python
# 所有损失都使用 CrossEntropyLoss(logits, labels)
fused_loss = CrossEntropyLoss(fused_logits, labels)
face_loss = CrossEntropyLoss(face_logits, labels)
# ... 其他模态
```

**不再使用**:
- ❌ NLLLoss + log(probs)
- ❌ 分开计算 probs 和 logits

### 数值稳定性

```python
# 统一使用 clamp
eps = 1e-7
probs = torch.clamp(probs, min=eps, max=1.0-eps)
weights = torch.clamp(weights, min=eps, max=1.0-eps)
```

**不再使用**:
- ❌ `torch.nan_to_num(x, nan=0.0)` - 破坏梯度
- ❌ `x + 1e-9` - 不够安全

### NaN 处理

```python
# 检测并跳过
if torch.isnan(loss) or torch.isinf(loss):
    print("[WARNING] 跳过批次")
    continue
```

**不再使用**:
- ❌ 将 NaN 替换为 0
- ❌ 将 NaN 替换为其他值
