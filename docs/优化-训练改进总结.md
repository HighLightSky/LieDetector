# 训练改进总结

## 改进概述

基于示例代码（plan.py）的最佳实践，对训练器进行了4项关键改进，提升训练稳定性、可复现性和性能。

## 改进详情

### 1. 损失函数升级：从单一损失到三种损失组合

#### 改进前

```python
# 只使用 CrossEntropyLoss
criterion = nn.CrossEntropyLoss()
loss = criterion(logits, labels)
```

#### 改进后
```python
# 三种损失组合
loss = loss_task + ent_reg * 0.2 + loss_w_mse * 0.05
```

**三种损失说明：**

1. **任务损失（Task Loss）** - 使用 NLLLoss
   
   ```python
   fused_probs = output['probs']['fused']
   logp = torch.log(fused_probs + 1e-9)
   loss_task = nn.NLLLoss()(logp, labels)
   ```
   - 主要的分类损失
   - 确保模型正确预测标签
   
2. **熵正则化（Entropy Regularization）**
   ```python
   W = output['weights']  # 融合权重
   ent_reg = (W * torch.log(W + 1e-9)).sum(dim=1).mean()
   ```
   - 鼓励模型对融合权重有明确的偏好
   - 避免权重过于平均（如 [0.33, 0.33, 0.34]）
   - 权重系数：0.2

3. **权重一致性损失（Weight Consistency Loss）**
   ```python
   # 计算各模态在正确类别上的概率
   p_face = face_probs.gather(1, labels_col).squeeze(1)
   p_of = of_probs.gather(1, labels_col).squeeze(1)
   p_audio = audio_probs.gather(1, labels_col).squeeze(1)
   
   # 归一化为权重目标
   p_stack = torch.stack([p_face, p_of, p_audio], dim=1)
   p_norm = p_stack / (p_stack.sum(dim=1, keepdim=True) + 1e-9)
   
   # MSE损失：让融合权重与性能对齐
   loss_w_mse = F.mse_loss(W, p_norm.detach())
   ```
   - 让融合权重与各模态的实际性能对齐
   - 性能好的模态应该获得更高的权重
   - 权重系数：0.05（可配置）

**优势：**
- 更精细的损失控制
- 融合权重更合理
- 模型性能更好

**修改文件：**
- `trainer/loss_computer.py`

### 2. NaN 处理：从跳过批次到智能替换

#### 改进前
```python
# 检查并跳过包含NaN的批次
if self._has_nan_output(output):
    print(f"\n[WARNING] 前向传播产生NaN/Inf，跳过此批次")
    continue

if torch.isnan(loss) or torch.isinf(loss):
    print(f"\n[WARNING] NaN/Inf loss detected, skipping batch")
    continue

if self._has_nan_gradient():
    print(f"\n[WARNING] 梯度包含NaN/Inf，跳过此批次的参数更新")
    optimizer.zero_grad()
    continue
```

#### 改进后
```python
# 使用 torch.nan_to_num 替换 NaN/Inf
faces = torch.nan_to_num(faces, nan=0.0, posinf=1.0, neginf=0.0)
audios = torch.nan_to_num(audios, nan=0.0, posinf=1.0, neginf=0.0)
openfaces = torch.nan_to_num(openfaces, nan=0.0, posinf=1.0, neginf=0.0)

# 在损失计算中也处理NaN
fused_probs = torch.nan_to_num(fused_probs, nan=1e-9, posinf=1.0, neginf=1e-9)
loss = torch.nan_to_num(loss, nan=0.0, posinf=1e6, neginf=-1e6)
```

**处理位置：**
1. 输入数据（faces, audios, openfaces）
2. 模型输出（probs, logits, weights）
3. 损失值
4. 总损失

**优势：**
- 不会浪费数据（不跳过批次）
- 训练更稳定
- 更符合示例代码的做法

**修改文件：**
- `trainer/training_loop.py`
- `trainer/validation_loop.py`
- `trainer/loss_computer.py`

### 3. 随机性控制：更严格的可复现性

#### 改进前
```python
def set_seed(seed):
    torch.manual_seed(seed)
    torch.cuda.manual_seed_all(seed)
    import numpy as np
    import random
    np.random.seed(seed)
    random.seed(seed)
```

#### 改进后
```python
def set_seed(seed):
    import os
    import numpy as np
    import random
    
    os.environ["PYTHONHASHSEED"] = str(seed)  # ✨ 新增
    random.seed(seed)
    np.random.seed(seed)
    torch.manual_seed(seed)
    torch.cuda.manual_seed_all(seed)
    torch.backends.cudnn.deterministic = True  # ✨ 新增
    torch.backends.cudnn.benchmark = False     # ✨ 新增
```

**新增设置：**
1. `PYTHONHASHSEED` - 控制 Python 哈希随机化
2. `cudnn.deterministic = True` - 确保 cuDNN 操作可复现
3. `cudnn.benchmark = False` - 禁用自动调优（会慢一点，但更可复现）

**优势：**
- 极致的实验可复现性
- 相同种子产生完全相同的结果
- 便于调试和对比实验

**注意：**
- `cudnn.benchmark = False` 会略微降低速度（约 5-10%）
- 但对于科研和调试来说，可复现性更重要

**修改文件：**
- `train.py`


### 自定义损失权重

```python

    loss_weights={'face': 0.2, 'audio': 0.2, 'openface': 0.2},
```
