# 模型总体架构

## 概述

本项目采用**多模态融合架构**进行谎言检测，整合人脸图像、音频和OpenFace特征三种模态信息。

## 核心组件

### 1. 特征提取层

#### 1.1 人脸特征提取 (FacesModel)
- **骨干网络**: MobileNetV3-Small (预训练)
- **输出维度**: 1024维
- **状态**: 冻结（不训练）
- **作用**: 提取通用视觉特征

#### 1.2 音频特征提取 (AudioExtractor)

- **模型**: Wav2Vec2-Base (预训练)
- **输出维度**: 768维
- **状态**: 冻结（不训练）
- **作用**: 提取语音语义特征

#### 1.3 OpenFace特征提取
- **工具**: OpenFace 2.0
- **输出维度**: 714维
- **特征**: 面部动作单元(AU)、头部姿态、眼神等
- **作用**: 提取细粒度面部行为特征

### 2. 融合模型 (FusionModel)

#### 2.1 单模态编码器 (UniEncoder)
**作用**: 对每个模态的时序特征进行编码

- **E_uni_face**: 
  - 输入: (B, T, 1024) 人脸特征序列
  - 结构: Linear → Transformer → AvgPool
  - 输出: (B, 256) 人脸表示

- **E_uni_of**:
  - 输入: (B, T, 714) OpenFace特征序列
  - 结构: Linear → Transformer → AvgPool
  - 输出: (B, 256) OpenFace表示

- **E_uni_audio**:
  - 输入: (B, 768) 音频特征
  - 结构: MLP (768→512→256)
  - 输出: (B, 256) 音频表示

#### 2.2 跨模态注意力 (CrossAttention)
**作用**: 学习模态间的交互关系

- **E_com_fa_au**: Face ↔ Audio 交互
  - 输入: Face特征序列, Audio特征
  - 输出: (B, 256) 交互表示

- **E_com_fa_of**: Face ↔ OpenFace 交互
  - 输入: Face特征序列, OpenFace特征序列
  - 输出: (B, 256) 交互表示

#### 2.3 动态权重模块 (W)
**作用**: 学习三个模态的重要性权重

- 输入: U_face, U_of, U_audio (各256维)
- 结构: MLP (768→256→3)
- 输出: W = [w_face, w_of, w_audio] (和为1)

#### 2.4 分类头
**作用**: 多任务学习，同时优化各个任务

1. **单模态分类**:
   - Face分类器: 基于face_frame_logits
   - OpenFace分类器: 基于of_frame_logits
   - Audio分类器: 基于audio特征

2. **跨模态融合分类**:
   - Face-Audio融合: prob_fa_au
   - Face-OpenFace融合: prob_fa_of

3. **最终融合**:
   - 加权组合: W[0]×P_face + W[1]×P_of + W[2]×P_fa_au
   - 输出: 最终预测概率

## 关键设计特点

### 1. 保留高维特征
```
旧方法: 1024维 → [分类头] → 2维 → [融合]
        ↑ 信息瓶颈

新方法: 1024维 → [Transformer] → 256维 → [融合]
        ↑ 保留丰富信息
```

### 2. 时序建模
- 使用Transformer处理视频帧序列
- 捕捉时间维度的动态变化
- 适应不同长度的视频

### 3. 跨模态交互
- 不是简单拼接，而是学习交互
- Cross-Attention机制
- 发现模态间的互补信息

### 4. 动态权重
- 不同样本，不同模态重要性不同
- 自适应学习权重
- 提高模型鲁棒性

### 5. 多任务学习
- 6个任务同时优化
- 共享表示学习
- 防止过拟合

## 输入输出规格

### 输入
```python
{
    'faces': torch.Tensor,      # (B, T, 3, 160, 160) 人脸图像序列
    'openfaces': torch.Tensor,  # (B, T, 714) OpenFace特征序列
    'audios': torch.Tensor      # (B, 768) 音频特征
}
```

### 输出
```python
{
    'logits': {
        'face': (B, 2),      # 人脸分类logits
        'openface': (B, 2),  # OpenFace分类logits
        'audio': (B, 2),     # 音频分类logits
        'fa_au': (B, 2),     # Face-Audio融合logits
        'fa_of': (B, 2),     # Face-OpenFace融合logits
    },
    'probs': {
        'face': (B, 2),      # 人脸分类概率
        'openface': (B, 2),  # OpenFace分类概率
        'audio': (B, 2),     # 音频分类概率
        'fa_au': (B, 2),     # Face-Audio融合概率
        'fa_of': (B, 2),     # Face-OpenFace融合概率
        'fused': (B, 2)      # 最终融合概率 ⭐
    },
    'weights': (B, 3),       # 模态权重 [w_face, w_of, w_audio]
    'cos': {                 # 余弦相似度
        'fa_fa_au': (B,),
        'fa_fa_of': (B,),
        'au_fa_au': (B,),
        'of_fa_of': (B,)
    }
}
```

## 与传统方法对比

| 特性 | 传统方法 | 本模型 |
|------|---------|--------|
| 特征融合 | 简单拼接 | Transformer+Attention |
| 时序建模 | 平均池化 | Transformer编码器 |
| 模态交互 | 无 | Cross-Attention |
| 权重分配 | 固定 | 动态学习 |
| 训练策略 | 单任务 | 多任务学习 |
| 信息利用 | 2维logits | 高维特征(256维) |

## 优势

1. **信息保留**: 使用高维特征而非压缩的logits
2. **时序建模**: Transformer捕捉视频动态
3. **模态交互**: Cross-Attention学习互补信息
4. **自适应**: 动态权重适应不同样本
5. **鲁棒性**: 多任务学习提高泛化能力
6. **可解释**: 可以查看各模态贡献和权重
