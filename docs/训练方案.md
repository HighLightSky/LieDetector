## 详细步骤

### 步骤1: 数据准备

#### 1.1 下载和切片视频

```bash
# 下载YouTube视频并切片
python -c "from dataloader.video_downloader import VideoDownloader; \
           downloader = VideoDownloader(); \
           downloader.run()"
```

**输出**:
- `src/videos/full/` - 完整视频
- `src/videos/cut/` - 切片视频
- `src/dataset/video_labels.csv` - 标签文件

#### 1.2 提取特征

```bash
# 提取所有特征（人脸、音频、OpenFace）
python dataloader/precompute_features.py
```

**输出**:
- `src/features/video_name_faces.pt` - 人脸特征 (T, 3, 160, 160)
- `src/features/video_name_audios.pt` - 音频特征 (768,)
- `src/features/video_name_openfaces.pt` - OpenFace特征 (T, 714)

### 步骤2: 数据加载

```python
from trainer import LieDetectionDataset
from torch.utils.data import DataLoader, random_split

# 加载数据集
dataset = LieDetectionDataset(
    csv_path='src/dataset/video_labels.csv',
    features_dir='src/features',
    use_openface=True
)

# 划分训练/验证集 (80/20)
train_size = int(0.8 * len(dataset))
val_size = len(dataset) - train_size
train_set, val_set = random_split(dataset, [train_size, val_size])

# 创建DataLoader
train_loader = DataLoader(
    train_set,
    batch_size=8,
    shuffle=True,
    collate_fn=LieDetectionDataset.collate_fn,
    num_workers=0  # Windows建议设为0
)

val_loader = DataLoader(
    val_set,
    batch_size=8,
    shuffle=False,
    collate_fn=LieDetectionDataset.collate_fn,
    num_workers=0
)
```

### 步骤3: 模型初始化

```python
from models.fusion import FusionModel

model = FusionModel(
    device='cuda',
    freeze_backbones=True,      # 冻结MobileNetV3
    num_classes=2,
    visual_hidden=256,
    fusion_hidden=128,
    dropout=0.3,
    uni_layers=2,
    uni_nhead=4,
    com_heads=4
)
```

**参数说明**:
- `freeze_backbones=True`: 冻结预训练的MobileNetV3，只训练融合层
- `visual_hidden=256`: 统一的特征表示维度
- `fusion_hidden=128`: 融合层隐藏层维度
- `uni_layers=2`: Transformer编码器层数
- `uni_nhead=4`: Transformer注意力头数
- `com_heads=4`: 跨模态注意力头数
- `dropout=0.3`: 防止过拟合

### 步骤4: 训练配置

```python
from trainer import FusionModelTrainer

# 损失权重配置
loss_weights = {
    'face': 0.2,        # 人脸分类损失
    'openface': 0.2,    # OpenFace分类损失
    'audio': 0.2,       # 音频分类损失
    'fa_au': 0.15,      # Face-Audio融合损失
    'fa_of': 0.15,      # Face-OpenFace融合损失
    'fused': 1.0        # 最终融合损失（权重最高）
}

# 创建训练器
trainer = FusionModelTrainer(
    model=model,
    train_loader=train_loader,
    val_loader=val_loader,
    device='cuda',
    save_dir='checkpoints',
    loss_weights=loss_weights
)
```

### 步骤5: 开始训练

```python
trainer.train(
    num_epochs=30,          # 训练轮数
    lr=1e-4,                # 学习率
    weight_decay=1e-4,      # 权重衰减
    patience=5,             # 早停耐心值
    verbose=True            # 显示详细信息
)
```

## 训练策略详解

### 多任务学习

模型同时优化6个任务：

```python
# 总损失计算
total_loss = (
    0.2 * loss_face +       # 人脸分类
    0.2 * loss_openface +   # OpenFace分类
    0.2 * loss_audio +      # 音频分类
    0.15 * loss_fa_au +     # Face-Audio融合
    0.15 * loss_fa_of +     # Face-OpenFace融合
    1.0 * loss_fused        # 最终融合（主任务）
)
```

**优势**:
1. 各模态学习自己的表示
2. 融合层学习整合策略
3. 共享参数提供正则化
4. 提高泛化能力

### 学习率调度

使用 `ReduceLROnPlateau`:

```python
scheduler = torch.optim.lr_scheduler.ReduceLROnPlateau(
    optimizer,
    mode='max',         # 监控验证准确率（越大越好）
    factor=0.5,         # 学习率衰减因子
    patience=5,         # 5个epoch没改进就降低学习率
    verbose=True
)
```

**学习率变化**:
```
Epoch 1-10:  lr = 1e-4
Epoch 11-20: lr = 5e-5  (如果没改进)
Epoch 21-30: lr = 2.5e-5 (如果继续没改进)
```

### 早停机制

```python
# 如果连续 patience*2 个epoch验证准确率没有提升，停止训练
if no_improve_count >= patience * 2:
    print("早停: 验证准确率不再提升")
    break
```

### 优化器

使用 AdamW (Adam + 权重衰减):

```python
optimizer = torch.optim.AdamW(
    trainable_params,
    lr=1e-4,
    weight_decay=1e-4  # L2正则化
)
```

## 训练监控

### 关键指标

1. **训练损失** (train_loss)
   - 应该持续下降
   - 如果震荡，降低学习率

2. **验证损失** (val_loss)
   - 应该下降
   - 如果上升，可能过拟合

3. **验证准确率** (val_acc)
   - 主要优化目标
   - 用于保存最佳模型

4. **详细损失** (loss_detail)
   - 各任务的损失
   - 帮助诊断问题

## 常见问题与解决

### 问题1: 训练损失不下降

**可能原因**:
- 学习率过高或过低
- 数据有问题
- 模型初始化不当

**解决方案**:
```python
# 降低学习率
trainer.train(lr=5e-5)

# 检查数据
for batch in train_loader:
    print(batch['faces'].shape)
    print(batch['labels'])
    break

# 重新初始化模型
model = FusionModel(device='cuda')
```

### 问题2: 验证准确率不提升

**可能原因**:
- 过拟合
- 验证集太小
- 数据不平衡

**解决方案**:
```python
# 增加Dropout
model = FusionModel(dropout=0.5)

# 增加权重衰减
trainer.train(weight_decay=1e-3)

# 增加验证集
train_set, val_set = random_split(dataset, [0.7, 0.3])

# 检查数据平衡
print(dataset.df['label'].value_counts())
```

### 问题3: 训练速度慢

**解决方案**:
```python
# 增加num_workers
train_loader = DataLoader(dataset, num_workers=8)

# 使用pin_memory
train_loader = DataLoader(dataset, pin_memory=True)

# 减少batch_size（如果GPU利用率低）
trainer.train(batch_size=4)

# 减少num_frames
face_extractor = FaceExtractor(num_frames=8)
```

### 问题4: CUDA out of memory

**解决方案**:
```python
# 减小batch_size
trainer.train(batch_size=4)

# 减小模型
model = FusionModel(visual_hidden=128, fusion_hidden=64)

# 使用CPU
model = FusionModel(device='cpu')
trainer = FusionModelTrainer(model, ..., device='cpu')
```

### 部署到检测器

from detector import LieDetector

# 方法1: 从检查点创建检测器（推荐）
detector = LieDetector.from_checkpoint(
    checkpoint_path='checkpoints/best_model.pth',
    device='cuda'
)

# 方法2: 手动创建
from models.fusion import FusionModel
from dataloader import FaceExtractor, AudioExtractor, OpenFaceExtractor

model = FusionModel(device='cuda')
checkpoint = torch.load('checkpoints/best_model.pth')
model.load_state_dict(checkpoint['model_state_dict'])

    model=model,
    face_extractor=face_extractor,
    audio_extractor=audio_extractor,
    openface_extractor=openface_extractor,
    device='cuda'

# 测试
result = detector.predict('test_video.mp4', verbose=True)
print(f"预测: {result['label_cn']}, 置信度: {result['confidence']:.2%}")

video_paths = ['video1.mp4', 'video2.mp4', 'video3.mp4']

### 关键要点

1. **多任务学习**: 同时优化6个任务，提高泛化能力
2. **冻结Backbone**: 只训练融合层，减少参数量
3. **加权损失**: 融合任务权重最高，其他任务辅助
4. **学习率调度**: 自动降低学习率，提高收敛
5. **早停机制**: 防止过拟合，节省时间
6. **详细监控**: 追踪各任务损失，及时发现问题
