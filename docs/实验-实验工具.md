## 概述

实验工具模块（`utils/experiment_tools.py`）提供了一套完整的实验数据可视化工具，用于分析训练过程中的各项指标。

### 主要功能

- ✅ 绘制损失曲线（训练/验证）
- ✅ 绘制准确率曲线（训练/验证）
- ✅ 绘制各模态损失曲线
- ✅ 绘制综合概览图（2x2子图）
- ✅ 自定义绘图（灵活配置）
- ✅ 自动生成时间戳文件名
- ✅ SVG格式输出（矢量图，可缩放）

## 工具详解

### 1. ExperimentVisualizer 类

#### 初始化

```python
from utils.experiment_tools import ExperimentVisualizer

visualizer = ExperimentVisualizer(
    history_path="checkpoints/training_history.json"  # 训练历史文件路径
)
```

---

### 2. 绘制损失曲线

```python
loss_path = visualizer.plot_loss_curves(
    show_train=True,    # 是否显示训练损失
    show_val=True,      # 是否显示验证损失
    output_dir="experiment_history/svg",  # 输出目录
    figsize=(10, 6)     # 图像大小
)
```

**功能**: 绘制训练和验证损失随epoch的变化曲线

**输出示例**:
- 文件名: `20260210_143025_loss_curves.svg`
- 内容: 蓝色线（训练损失）+ 红色线（验证损失）

---

### 3. 绘制准确率曲线

```python
acc_path = visualizer.plot_accuracy_curves(
    show_train=True,    # 是否显示训练准确率
    show_val=True,      # 是否显示验证准确率
    output_dir="experiment_history/svg",  # 输出目录
    figsize=(10, 6)     # 图像大小
)
```

**功能**: 绘制训练和验证准确率随epoch的变化曲线

**输出示例**:
- 文件名: `20260210_143026_accuracy_curves.svg`
- 内容: 蓝色线（训练准确率）+ 红色线（验证准确率）

---

### 4. 绘制模态损失曲线

```python
modality_path = visualizer.plot_modality_losses(
    modalities=['face', 'openface', 'audio', 'task'],  # 要绘制的模态
    split='train',      # 'train' 或 'val'
    output_dir="experiment_history/svg",  # 输出目录
    figsize=(12, 8)     # 图像大小
)
```

**功能**: 绘制各个模态的损失曲线

**可用模态**:
- `face`: 人脸模态损失
- `openface`: OpenFace模态损失
- `audio`: 音频模态损失
- `fa_au`: Face-Audio融合损失
- `fa_of`: Face-OpenFace融合损失
- `fused`: 最终融合损失
- `task`: 任务损失
- `entropy_reg`: 熵正则化
- `weight_mse`: 权重MSE

**输出示例**:
- 文件名: `20260210_143027_train_modality_losses.svg`
- 内容: 多条彩色曲线，每条代表一个模态

---

### 5. 绘制综合概览图

```python
overview_path = visualizer.plot_combined_overview(
    output_dir="experiment_history/svg",  # 输出目录
    figsize=(16, 10)    # 图像大小
)
```

**功能**: 在一张图中展示4个子图

**子图内容**:
1. **左上**: 损失曲线（训练 vs 验证）
2. **右上**: 准确率曲线（训练 vs 验证）
3. **左下**: 训练模态损失（face, openface, audio, task）
4. **右下**: 验证模态损失（face, openface, audio, task）

**输出示例**:
- 文件名: `20260210_143029_combined_overview.svg`
- 内容: 2x2子图布局

---

### 6. 自定义绘图

```python
custom_path = visualizer.plot_custom(
    metrics=['train_loss', 'val_loss'],  # 要绘制的指标
    labels=['训练损失', '验证损失'],      # 图例标签
    title="自定义损失曲线",               # 图表标题
    output_dir="experiment_history/svg",  # 输出目录
    figsize=(10, 6)                      # 图像大小
)
```

**功能**: 灵活绘制任意指标的曲线

**可用指标**:
- `train_loss`: 训练损失
- `train_acc`: 训练准确率
- `val_loss`: 验证损失
- `val_acc`: 验证准确率


### 示例5: 批量生成所有图表

```python

visualizer = ExperimentVisualizer()

# 生成所有常用图表
paths = []
paths.append(visualizer.plot_loss_curves())
paths.append(visualizer.plot_accuracy_curves())
paths.append(visualizer.plot_modality_losses(split='train'))
paths.append(visualizer.plot_modality_losses(split='val'))
paths.append(visualizer.plot_combined_overview())

print(f"共生成 {len(paths)} 张图表")
for path in paths:
    print(f"  - {path}")
```

## 输出说明

### 文件命名规则

所有生成的图表文件名格式为：

```

```

**示例**:
- `20260210_143025_loss_curves.svg`
- `20260210_143026_accuracy_curves.svg`
- `20260210_143027_train_modality_losses.svg`

```
experiment_history/
```

## 常见问题

### Q1: 如何修改图表样式？

**A**: 直接修改 `utils/experiment_tools.py` 中的绘图代码，例如：

```python
# 修改线条样式
plt.plot(epochs, data, 'b--', linewidth=3)  # 蓝色虚线，粗细3

# 修改颜色
plt.plot(epochs, data, color='#FF5733')  # 自定义颜色

# 修改字体大小
plt.xlabel('Epoch', fontsize=16)
```

### Q2: 如何导出PNG格式？

**A**: 修改 `savefig` 的 `format` 参数：

```python
plt.savefig(filepath.replace('.svg', '.png'), format='png', dpi=300)
```

### Q3: 如何在图表中添加网格？

**A**: 已默认添加，可通过以下方式调整：

```python
plt.grid(True, alpha=0.5, linestyle='--')  # 虚线网格，透明度0.5
```

### Q4: 如何同时保存多种格式？

**A**: 多次调用 `savefig`：

```python
plt.savefig(filepath, format='svg')
plt.savefig(filepath.replace('.svg', '.png'), format='png', dpi=300)
plt.savefig(filepath.replace('.svg', '.pdf'), format='pdf')
```
