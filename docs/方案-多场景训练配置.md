## 不同场景的配置

### 场景1: 小数据集（<100样本）

```bash
python train.py \
    --num_epochs 20 \
    --batch_size 4 \
    --lr 5e-5 \
    --dropout 0.5 \
    --visual_hidden 128 \
    --fusion_hidden 64 \
    --patience 3
```

**特点**:
- 较小的batch size避免过拟合
- 较低的学习率
- 较高的dropout
- 较小的模型容量
- 较短的耐心值

### 场景2: 中等数据集（100-1000样本）

```bash
python train.py \
    --num_epochs 30 \
    --batch_size 8 \
    --lr 1e-4 \
    --dropout 0.3 \
    --visual_hidden 256 \
    --fusion_hidden 128 \
    --patience 5
```

**特点**:
- 标准配置
- 平衡的模型容量
- 适中的正则化

### 场景3: 大数据集（>1000样本）

```bash
python train.py \
    --num_epochs 50 \
    --batch_size 16 \
    --lr 1e-4 \
    --dropout 0.2 \
    --visual_hidden 512 \
    --fusion_hidden 256 \
    --patience 10
```

**特点**:
- 更大的batch size提高训练效率
- 更大的模型容量
- 较低的dropout（数据充足）
- 更长的耐心值

### 场景4: GPU内存有限

```bash
python train.py \
    --batch_size 4 \
    --visual_hidden 128 \
    --fusion_hidden 64 \
    --num_workers 0
```

**特点**:
- 减小batch size
- 减小模型尺寸
- 禁用多进程加载

### 场景5: 只使用CPU

```bash
python train.py \
    --device cpu \
    --batch_size 2 \
    --num_workers 0
```

**特点**:
- 指定CPU设备
- 极小的batch size
- 禁用多进程

## 高级用法

### 1. 从检查点恢复训练

如果训练中断，可以从最新检查点恢复：

```bash
python train.py --resume checkpoints/latest_model.pth
```

这将：
- 加载模型权重
- 恢复训练历史
- 继续训练

### 2. 调整学习率

如果训练不收敛：

```bash
# 降低学习率
python train.py --lr 5e-5

# 或更低
python train.py --lr 1e-5
```

### 3. 调整模型容量

如果过拟合：

```bash
# 减小模型
python train.py \
    --visual_hidden 128 \
    --fusion_hidden 64 \
    --dropout 0.5
```

如果欠拟合：

```bash
# 增大模型
python train.py \
    --visual_hidden 512 \
    --fusion_hidden 256 \
    --uni_layers 4 \
    --dropout 0.2
```

### 4. 自定义保存目录

```bash
python train.py --save_dir experiments/exp001
```

### 5. 设置随机种子（可复现）

```bash
python train.py --seed 42
```

## 常见问题

### Q1: 训练损失不下降

**可能原因**:
- 学习率过高或过低
- 数据有问题
- 模型初始化不当

**解决方案**:
```bash
# 降低学习率
python train.py --lr 5e-5

# 检查数据
python -c "from trainer import LieDetectionDataset; \
           ds = LieDetectionDataset('src/dataset/video_labels.csv', 'src/features'); \
           print(f'数据集大小: {len(ds)}'); \
           print(ds.df['label'].value_counts())"
```

### Q2: 验证准确率不提升

**可能原因**:
- 过拟合
- 验证集太小
- 数据不平衡

**解决方案**:
```bash
# 增加正则化
python train.py --dropout 0.5 --weight_decay 1e-3

# 增加验证集
python train.py --val_split 0.3

# 检查数据平衡
python -c "from trainer import LieDetectionDataset; \
           ds = LieDetectionDataset('src/dataset/video_labels.csv', 'src/features'); \
           print(ds.df['label'].value_counts())"
```

### Q3: CUDA out of memory

**解决方案**:
```bash
# 减小batch size
python train.py --batch_size 4

# 减小模型
python train.py --visual_hidden 128 --fusion_hidden 64

# 使用CPU
python train.py --device cpu --batch_size 2
```

### Q4: 训练速度慢

**解决方案**:
```bash
# 增加num_workers（非Windows）
python train.py --num_workers 4

# 使用GPU
python train.py --device cuda

# 增加batch_size
python train.py --batch_size 16
```

### Q5: 特征文件不存在

**错误信息**:
```
✗ 标签文件不存在: src/dataset/video_labels.csv
```

**解决方案**:
```bash
# 1. 下载和切片视频
python -c "from dataloader.video_downloader import VideoDownloader; VideoDownloader().run()"

# 2. 提取特征
python dataloader/precompute_features.py
```

## 最佳实践

- 从默认参数开始

- 使用验证集选择最佳参数

- 观察训练/验证曲线
- 检查详细损失
- 注意过拟合迹象

### 4. 模型保存

- 保存最佳模型用于部署
- 保存最新模型用于恢复
- 记录训练配置

### 5. 实验管理

- 使用不同的save_dir
- 记录超参数
- 保存训练日志

## 完整训练流程示例

```bash
# 1. 准备数据
echo "步骤1: 下载和切片视频"
python -c "from dataloader.video_downloader import VideoDownloader; VideoDownloader().run()"

echo "步骤2: 提取特征"
python dataloader/precompute_features.py

# 2. 训练模型
echo "步骤3: 训练模型"
python train.py \
    --num_epochs 30 \
    --batch_size 8 \
    --lr 1e-4 \
    --device cuda \
    --save_dir checkpoints/exp001

# 3. 评估模型
echo "步骤4: 评估模型"
python -c "
from detector import LieDetector
detector = LieDetector.from_checkpoint('checkpoints/exp001/best_model.pth')
result = detector.predict('test_video.mp4')
print(f'预测: {result[\"label_cn\"]}, 置信度: {result[\"confidence\"]:.2%}')
"

echo "训练完成！"
```
